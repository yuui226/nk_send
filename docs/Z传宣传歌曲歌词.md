# Z传宣传歌曲《你还缺个 Z传》

## 成片定位

- **用途**：约 3 分钟的产品宣传 MV。
- **核心产品**：Z传首先是一款把尼康相机文件传到手机的工具。
- **叙事顺序**：无线传输 → 无线遥控 → 有线高速传输 → 两种模式总结。
- **两种模式的区别**：
  - 无线模式：不用带线，相机按三下开启热点，手机连接后即可浏览、挑选和传输。
  - 有线模式：一根 USB C to C 数据线直连，不受 Wi-Fi 传输速度限制，实测速度至少提高十倍。
- **其他功能权重**：遥控作为无线连接后的重要扩展；边框只用一句带过，不单独展开。
- **风格**：112–116 BPM、4/4 拍的轻快中文流行电子 / City Pop，语气俏皮、有梗，功能密集处使用半说唱。
- **歌词原则**：每一句都对应具体操作、功能或使用结果，不写抽象抒情句。
- **开场要求**：第一声快门后立刻进人声，前 5 秒唱到“尼康相机”和“还缺一个 Z传”。
- **核心记忆点**：`无线不用线，有线冲极限。`

## 演唱与剪辑注意

- 开场只定义 Z传的核心用途：把尼康相机原片传到手机，并提供无线、有线两种模式。不要在开场强调边框。
- “相机只需按三下”必须配真实连续操作。建议画面同步显示 `① i 键 → ② Wi-Fi 连接 → ③ 确认开启`，让观众知道三下分别按什么。
- 无线段先完整讲完，进入 Bridge 前不要提前出现 C to C 线，避免两种模式混在一起。
- “本地直连不经云端”只指相机文件传输链路，画面使用“相机 → 手机”直连，不出现服务器。
- “至少快十倍”属于可验证的性能宣称。成片必须使用同一台相机、同一部手机、同一个文件分别实测 Wi-Fi 与 USB，并同时展示速度和耗时；如果最终实测不足十倍，应按结果修改歌词和字幕。
- Bridge 的画面要把原因说清：Wi-Fi 无线链路限制速度，USB 直接传输不经过 Wi-Fi。不要只放一个“×10”动画。
- 边框只在 Rhythm 最后一句出现一次，画面展示派生图另存且原片未被覆盖，不再逐款介绍样式。
- `C to C` 可唱作“西 to 西”，字幕保持 `C to C`；`RAW` 唱作英文 “raw”，字幕保持大写。
- 遥控段使用已经真机验证兼容的尼康机身，不写“尼康全系支持”。
- 最后反复记忆点是“无线不用线，有线冲极限”，唱完产品名后直接落快门声。
