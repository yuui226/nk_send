# Z传第二首宣传歌曲备选特点

## 使用说明

这份清单用于挑选第二首宣传歌曲最终要介绍的产品特点，暂不代表最终歌词结构。

- 第二首仍需让第一次听到的人立刻知道：Z传可以把尼康相机原片传到手机。
- 传输与两种连接方式属于核心卖点，但篇幅可以比第一首更短。
- 第二首的新增重点建议放在“照片效果工作台”和“专业监看辅助”。
- 正式歌词继续保持第一首的特点：简短、口语、押韵、有画面感，不写成功能说明书。

建议最终选择约 8～10 个特点，并把相关能力合并表达。

## 一、传输与连接

第二首需要保留这一部分，但不再重复第一首的详细连接教程。

- [ ] 尼康相机原片直接传入手机
  - Z传最核心、最能吸引用户下载的能力。
  - 适合放在开头，很快说明软件是做什么的。

- [ ] Wi-Fi 无线传输
  - 突出不插线、随时传、操作方便。

- [ ] C to C 有线传输
  - 突出批量传输和大文件场景下的速度。

- [ ] 无线方便，有线高速
  - 可以把两种连接方式合成一个简短、形成对比的记忆点。

- [ ] 原片、RAW 和视频都能传输
  - 强调不是压缩后的社交分享图，而是相机中的原始文件。
  - 正式歌词中可以只说“原片”，不必罗列格式名称。

- [ ] 批量传输与进度可见
  - 适合与“大量照片也不慌”一类使用场景结合。
  - 第一首已经详细介绍，第二首可选，不建议重点展开。

- [ ] 大文件分块、断线后可继续
  - 属于可靠性卖点，但技术意味较重。
  - 更适合转化成“断了重连接着传”，不直接唱技术名词。

## 二、滤镜、边框与水印

这是第二首最值得重点介绍的新能力。

- [ ] 滤镜、边框、水印一站完成
  - 最适合作为照片效果段落的总领句。
  - 能直接建立“手机摄影工作台”的产品印象。

- [ ] 多种风格滤镜
  - 可以强调照片传到手机后立即选择喜欢的色彩风格。

- [ ] 滤镜浓淡可以调节
  - 比只说“有滤镜”更具体，适合表达“浓淡由你掌握”。

- [ ] 多种照片边框
  - 包括简洁留白、暗色、毛玻璃、铭牌等不同方向。
  - 歌词中无需逐个念出样式名称。

- [ ] 文字水印和 Logo 水印
  - 既适合普通用户署名，也能突出摄影师个人品牌。

- [ ] 字体、颜色、大小、位置都能调整
  - 可以浓缩为“字体颜色位置任你挑”，无需逐项说明。

- [ ] 原片不修改，效果图另外保存
  - 能消除用户担心原图被覆盖的顾虑。
  - “原片保留、效果另存”简洁、清楚，也容易写进歌词。

- [ ] 传输完成后自动生成效果图
  - 能把“传输”和“照片效果”两段自然连接起来。

- [ ] 手机相册里的照片也能处理
  - 不局限于刚从相机传下来的照片。
  - 可以体现 Z传同时是一套独立的照片效果工作台。

- [ ] 收藏常用效果组合
  - 常用滤镜、边框、水印搭配可以快速复用。
  - 属于效率卖点，优先级低于一站式效果和原片保留。

## 三、遥控与监看

第一首已经说过“手机变身监视屏”，第二首可以展开其专业辅助能力。

- [ ] 手机变成高清监视屏
  - 监看部分最容易理解的入口卖点。
  - 可以突出比相机小屏看得更舒服、更清楚。

- [ ] 高清监看和全屏取景
  - 适合合并成一句，不必解释 XGA 等技术规格。

- [ ] 横竖旋转，适应不同机位
  - 有明确的使用画面，也容易与全屏监看放在一起。

- [ ] 点按画面选择对焦位置
  - 可以提炼成“想对哪里点哪里”，口语化且有记忆点。

- [ ] 快门按住对焦、松手拍摄
  - 第一首已经介绍，可作为呼应，也可以省略给新功能腾出篇幅。

- [ ] 光圈、快门、ISO 等曝光参数遥控调节
  - 第一首已经概括为“曝光要素都能调”。
  - 第二首若保留，建议只用一句带过。

- [ ] 相机对焦框和合焦反馈
  - 监看画面可以显示对焦位置和结果。
  - 可与点按对焦合并，不建议单独占用一句。

- [ ] 遥控拍照与录像
  - 是监看之后最直接的动作，建议保留。

- [ ] 将手机监看画面录制成视频
  - 支持录制、暂停、继续，也可以带声音。
  - 是有辨识度的能力，但容易与“控制相机录像”混淆，正式歌词需要表达清楚。

## 四、可以作为补充的特点

这些特点真实有用，但如果歌词篇幅有限，应排在三条主线之后。

- [ ] 日期、格式、保护状态、连拍和未传状态筛选
  - 第一首已经充分介绍，不建议第二首重复展开。

- [ ] 连拍照片自动合成一组
  - 第一首已有清晰表达，可以省略。

- [ ] 高清预览、双指放大
  - 第一首已经介绍，可以省略。

- [ ] 后台或锁屏时继续传输
  - 实用但画面感稍弱，适合一句可靠性表达。

- [ ] 视频虽然暂不播放，但可查看大小和拍摄时间
  - 属于体验补充，不建议占用宣传歌曲篇幅。

- [ ] 多种界面主题和相机风格按键
  - 有视觉辨识度，但不是促使用户首次下载的核心原因。

## 五、建议的歌曲结构

在最终特点确定后，可以按照以下比例写词：

1. 开场记忆点：3～4 句。
2. 原片传输、Wi-Fi 与 C to C：4～6 句。
3. 滤镜、边框、水印：6～8 句。
4. 高清监看和拍摄辅助：8～10 句。
5. 副歌总结：4～6 句。

建议总长度控制在约 28～32 句，与第一首接近。

## 六、候选核心表达

这些不是最终歌词，只用于确定第二首想让用户记住什么。

- 原片传得快，拍摄看得准，照片更好看。
- 从相机到手机，从取景到出片。
- 拍的时候帮你看，拍完以后帮你变好看。
- 无线图方便，有线拼速度。
- 传得快，看得全，出片还得看 Z传。

## 七、待最终挑选

正式写歌词前，建议确定以下内容：

- 传输段最终保留哪些特点。
- 照片效果段最终保留哪些特点。
- 监看段最终保留哪些特点。
- 是否加入手机监看画面录制。
- 副歌更偏“传输速度”，还是更偏“传、拍、出片全流程”。
