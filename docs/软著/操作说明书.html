一、软件概述

Z传相机照片传输软件（以下简称“本软件”）是一款运行于 Android 操作系统的数码相机影像工作流工具。本软件可通过相机 Wi-Fi 热点或 USB 数据线与支持相应 PTP 能力的尼康数码相机连接，完成照片与视频的浏览、预览、传输、监看和遥控操作。

1.1 主要功能

  • Wi-Fi 热点与 USB 数据线两种相机连接方式；
  • 合并浏览相机双存储卡中的照片和视频；
  • 日期分组、格式筛选、保护筛选、连拍识别和未传输筛选；
  • 缩略图缓存、高清照片预览、EXIF 信息及照片手势操作；
  • 单张、连拍组和日期组队列传输，支持大文件分块与断点续传；
  • 相机实时监看、曝光参数调整、对焦、拍照和端侧录像；
  • 传输原图的同时生成独立的照片边框和文字或 Logo 水印效果图；
  • 简体中文、繁体中文和英文界面，支持明暗模式与多种按钮材质。

1.2 运行环境

项目要求
手机系统Android 8.0（API 26）及以上
手机硬件支持 Wi-Fi
USB 连接手机支持 USB Host/OTG，并使用可传输数据的连接线
配套相机支持本软件所用 PTP/IP 或 USB PTP 能力的尼康数码相机

1.3 文档术语

  • “相机文件”指保存在相机存储卡中、由软件读取的照片或视频。
  • “传输目录”指用户通过 Android 系统文件选择器授权的软件保存位置。
  • “监看”指在手机端查看相机实时取景画面，不代表手机会自动保存该画面。
  • “效果图”指基于已传输照片生成的边框或水印派生文件，原图不会被覆盖。

二、安装、启动与权限

2.1 安装与启动

通过正式分发渠道获取本软件安装包后，按 Android 系统提示完成安装。首次启动后进入连接页，用户可选择 Wi-Fi 或 USB 方式连接相机。

2.2 权限说明

权限或系统授权使用场景拒绝后影响
通知在文件传输或保持无线相机会话时显示状态通知可能不显示；建议允许以便观察后台状态
USB 设备访问手机通过数据线首次访问相机无法使用 USB 连接，Wi-Fi 连接不受影响

安装未知应用仅直接分发版在应用内安装更新包时使用可下载更新，但需手动授权后才能安装

2.3 联网说明

浏览、预览、传输和遥控相机时，数据主要在手机与相机的本地连接中传输。授权激活、权益恢复、购买、价格获取和检查更新需要访问互联网。激活时会将设备标识发送至授权服务器，用于授权绑定和验证。

本软件无用户账号登录体系，但不应表述为“完全不联网”或“不处理任何设备信息”。

三、选择连接方式与 Wi-Fi 连接

3.1 选择连接方式

启动软件后，连接页提供“相机热点”和“USB”两种方式。相机热点方式适合无线浏览、传输和遥控；USB 方式需要数据线，可在不占用手机 Wi-Fi 的情况下连接相机。

连接选择界面：页面提供“相机热点”和“USB”两个入口，并分别显示无线连接提示和数据线连接提示。

3.2 相机热点连接

  1. 在相机中开启“与智能设备建立 Wi-Fi 连接”或同类菜单，使相机进入 Wi-Fi AP 热点等待状态。
  2. 在手机系统 Wi-Fi 设置中连接相机显示的热点。该热点没有互联网属正常现象。
  3. 返回本软件。软件会识别相机网络并发起 PTP/IP 会话。
  4. 连接成功后自动进入照片列表页；连接中断时界面会显示断开或重连状态。
无线连接状态：界面根据当前阶段显示热点连接引导、正在连接、连接成功或连接失败信息。

四、USB 连接

  1. 确认手机支持 USB Host/OTG，相机已开机。
  2. 使用支持数据传输的 USB-C 数据线连接手机与相机。
  3. 在连接页选择“USB”。
  4. Android 系统显示 USB 设备访问对话框时，选择允许。如拒绝，需重新插拔数据线后再次授权。
  5. 软件读取相机设备信息并建立 USB PTP 会话，成功后进入照片列表页。

4.1 USB 异常处理

  • 显示“请打开相机电源”时，检查相机电源和自动关机状态。
  • 显示“未获得 USB 权限”时，拔下数据线，重新连接并允许系统授权。
  • 文件传输中不要拔线或关闭相机。中断后可重新连接并重试任务。
  • 只能充电、不支持数据传输的线材无法用于 USB 相机连接。
USB 连接结果：授权并建立 PTP 会话后进入照片列表；断线时返回连接状态并提示重新连接。

五、照片列表、分组与筛选

连接成功后，软件获取相机存储中的文件。相机同时使用两张存储卡时，支持将两张卡中可识别的照片和视频合并展示。

5.1 日期分组

  • 文件按拍摄日期分组，默认优先展示新照片。
  • 点击日期标题可收起或展开当日文件。
  • 点击日期组右侧的传输按钮，可将该组可传输文件加入队列。

5.2 筛选

点击顶部筛选按钮可按文件类型、相机保护标记、连拍属性和本地未传输状态组合筛选。未传输筛选根据当前传输目录中的文件名和大小进行判断。

5.3 连拍合集

开启“连拍成组”后，时间相近的连拍照片可以合集形式显示。点击合集可展开或收起成员，也可将整个连拍组加入传输队列。

5.4 刷新与文件状态

  • 重新连接相机后，软件会重新获取当前存储卡中的文件信息。
  • 缩略图会按需加载并缓存在手机本地，清除应用数据后需要重新生成缓存。
  • 筛选结果为空时，应先检查文件类型、保护、连拍和未传输等筛选条件。
照片列表结构：顶部为连接与筛选操作区，中部按日期展示缩略图网格，连拍文件可折叠为合集。

六、照片预览与手势

软件支持在照片列表中预览照片。默认操作为“点击传输、长按预览”，也可在设置中切换为“点击预览、长按传输”。

6.1 高清预览

  • 进入预览后，先显示已缓存图像，然后在相机支持时加载高清预览图。
  • 左右滑动可浏览相邻照片或连拍合集页。
  • 双指捏合可缩放，放大后可单指平移；双击可在原始比例与放大状态之间切换。
  • 点击旋转控件可调整预览方向，旋转状态会按文件保存。
  • 预览页可显示文件名、页序、拍摄参数等信息，并可将当前照片加入传输队列。

6.2 视频预览

视频文件可在列表中显示缩略图或视频标识，但当前版本不在照片预览器内播放相机中的视频。用户可先将视频传输到手机后使用其他播放器打开。

预览界面结构：中央显示高清照片，周围提供返回、传输、信息查看和前后切换操作。

七、选择目录与发起传输

7.1 设置传输目录

首次传输前，软件会引导用户通过 Android 系统文件选择器选择保存文件夹。授权保存后通常无需每次重选。如文件夹被删除、移动、卸载存储设备或系统撤销授权，软件会提示目录失效，需重新选择。

7.2 发起传输

  • 单张传输：按当前“照片操作”设置点击或长按缩略图。
  • 预览页传输：在照片预览中点击传输按钮。
  • 连拍组传输：在连拍合集中选择整组加入队列。
  • 日期组传输：点击日期分组右侧的传输按钮。

7.3 已存在文件

当传输目录中存在同名且大小匹配的完整文件时，任务可标记为已存在并跳过重复下载。同名但内容不同时，保存提供者可为新文件生成带序号的副本名，以避免覆盖已有文件。

7.4 免费版与高级版

免费版的每日传输数量、单文件大小和监看时长按当前界面显示的权益规则执行。已存在而跳过的文件不会被当作新传输完成计数。

传输状态：照片列表和任务队列使用进度、成功、失败等状态标识反馈当前任务结果。

八、传输队列与传输保障

点击照片列表顶部的队列状态控件可进入传输队列页。每个任务卡片显示缩略图、文件名、等待或传输状态、进度、速度、完成大小或失败原因。

8.1 队列管理

  • 等待、完成、失败或取消的任务可按界面提示移出队列。
  • 正在传输的文件不允许直接移除，以避免强制中断相机会话和写入过程。
  • 清空队列前会显示确认提示；正在传输的任务不受清空操作影响。
  • 失败任务可单独重试；存在多个失败任务时可按界面提示重试全部。

8.2 文件完整性

  • 下载期间使用隐藏的临时文件名，未完成前不以正式照片或视频名称出现。
  • 软件根据相机报告的文件大小和实际接收字节执行完整性检查。
  • 大文件或中断后重试的文件可使用分块传输；条件允许时从已完成块边界续传。
  • 文件完整后才改为正式文件名。如系统文件提供者不支持原子改名，软件使用完整复制回退并检查复制结果。
队列界面结构：每个任务卡片显示文件名、进度和状态，页面提供重试失败项、移除任务和清理队列操作。

九、相机监看与遥控拍摄

在照片列表页点击相机监看入口可进入遥控页。传输任务正忙时，软件可阻止进入或提示监看可能卡顿，以避免传输与监看同时竞争相机通信通道。

9.1 实时监看

  • 相机支持时，页面显示实时取景图像、当前模式、曝光参数和对焦反馈。
  • 可按需要开启直方图、构图参考线、斑马纹、水平仪、帧率显示等监看辅助工具。
  • 可切换全屏显示和屏幕方向，工具按钮在不同屏幕尺寸下自适应排列。

9.2 拍摄参数和对焦

  • 在相机和当前模式支持时，可调整快门、光圈、ISO、曝光补偿及相关自动参数。
  • 自动对焦模式下可在取景画面上点按对焦；手动对焦模式下会显示对应提示。
  • 点击快门按钮可发起遥控拍照。拍摄结果由相机返回事件或状态确认。

不同相机型号、固件版本、拍摄模式和当前菜单状态可能影响可用的遥控参数。界面会根据探测结果显示、禁用或隐藏不可用控件。

遥控界面结构：取景画面位于中央，曝光参数、对焦和快门控件分布在画面周围；实际可用项由相机能力决定。

十、端侧录像与监看工具

端侧录像是将本软件收到的相机监看画面编码为手机本地视频，不等同于操作相机存储卡中的原始视频文件。该功能属于高级版功能。

10.1 开始录像

  1. 进入相机监看页，确认取景画面正常。
  2. 点击录像按钮。如尚未授予麦克风权限，Android 系统会显示权限请求。
  3. 允许麦克风权限后可录制声音；拒绝时仍可录像，但保存为无声视频。
  4. 录像中可暂停、恢复或停止。画面会显示录制状态和累计时间。

10.2 录像文件保存

如已配置可写的传输目录，录像优先保存到该目录；目录不可用时可回退到应用私有目录。录像完成或失败后，界面会显示对应结果。

10.3 监看辅助工具

  • 直方图用于观察画面明暗分布；斑马纹用于提示高亮区域。
  • 构图参考线用于辅助画面布局；水平仪用于辅助判断设备姿态。
  • 高清监看需要相机支持，并可能增加通信和手机解码负载。
录像与辅助工具：界面显示录制状态和时长，并可打开直方图、斑马纹、构图参考线、水平仪等工具。

十一、照片边框与水印

开启“边框与水印”后，软件在传输 JPG、JPEG 或 PNG 原图的同时，可生成独立的效果图。原图仍按相机文件保存，效果图另存，不修改原图像素。RAW/NEF 文件可照常传输，但不直接用于生成边框或水印效果图。

11.1 边框

  • 可开启或关闭边框；关闭边框后可单独使用图内水印。
  • 可选择雾白、暗夜、简白、毛玻璃和铭牌等预设样式。
  • 不同预设会根据照片比例安排图片、相机信息和水印位置。

11.2 水印

  • 高级版可选择文字或 Logo 图片水印；免费版按当前权益规则使用默认水印。
  • 文字水印可设置文本、字体、大小、位置、颜色、透明度和可读性效果。
  • Logo 水印由用户从系统图片选择器导入，并复制到应用私有存储中。
  • 编辑页提供效果预览。保存设置后，后续符合条件的传输任务使用该配置生成效果图。

11.3 防止重复导出

软件根据原图、边框预设和水印配置生成稳定的效果图名称。相同配置的完整效果图已存在时可直接跳过重复渲染。

编辑界面结构：预览区实时展示当前效果，设置区用于选择边框预设、水印内容、位置、颜色和透明度。

十三、授权、购买与应用更新

13.1 免费版与高级版

本软件可以免费版状态使用基础功能。高级版可解锁更高或无限的传输与监看权益、端侧录像、自定义边框水印等功能。具体套餐、有效期、价格和权益以软件内当时显示为准。

13.2 激活与恢复

  • 用户可输入有效激活码完成高级版激活。
  • 激活时软件将设备标识发送至授权服务器，服务器返回签名授权凭证，软件在本地验证签名。
  • 重装后可按界面提示尝试恢复本机已有授权。换机前应妥善保存激活码。

13.3 购买

购买需要可访问互联网的默认网络。如手机正连接无互联网的相机热点，应先退出相机连接，等待手机恢复移动数据或其他可上网的 Wi-Fi。直接分发版可通过第三方支付页面完成购买，到账后自动激活或返回激活码。

13.4 检查更新

在设置页点击“检查更新”可查询新版本。检查和下载更新需要互联网。下载完成后软件会校验安装包信息，然后交由 Android 系统安装器完成安装。

授权与更新界面：授权区域显示当前权益状态和相关操作；版本区域提供当前版本信息及检查更新入口。

十四、常见问题

14.1 无法连接相机 Wi-Fi

确认相机已进入 Wi-Fi AP 等待连接状态，手机已连接相机热点，且没有被系统自动切换到其他网络。如相机拒绝会话，关闭后重新开启相机 Wi-Fi。

14.2 USB 连接无反应

检查相机电源、手机 OTG/USB Host 能力和数据线。拔线重连后允许 Android 系统显示的 USB 访问请求。

14.3 传输目录失效

目录被删除、移动、存储卡被卸载或系统撤销授权时，进入设置重新选择传输目录。

14.4 大文件传输中断

保持当前传输目录不变，恢复相机连接后重试失败任务。相机支持分块读取且临时文件身份匹配时，软件会从已完成的分块边界续传；不支持时会安全地从头重新传输。

14.5 购买或更新时提示没有网络

相机热点通常没有互联网。先退出相机连接，等待手机恢复移动数据或其他可上网的 Wi-Fi，再重试购买、激活或检查更新。

14.6 录像没有声音

进入 Android 系统的应用权限设置，检查是否允许本软件使用麦克风。拒绝麦克风权限时，软件会保存无声视频。

14.7 列表中找不到刚拍摄的照片

检查当前筛选条件，并重新连接或刷新相机文件。双卡相机还应确认照片实际写入的卡槽可被相机正常识别。

14.8 没有生成边框或水印效果图

确认边框与水印功能已经开启、传输文件为 JPG、JPEG 或 PNG，并检查当前授权权益与传输目录写入状态。

14.9 更新包无法安装

确认下载已经完成，并按 Android 系统提示允许当前来源安装应用。系统仍拒绝时，可使用正式分发渠道手动更新。

十五、数据与隐私摘要

  • 相机照片、视频、缩略图和实时监看数据主要在手机与相机之间传输。
  • 用户选择的传输目录和导入的 Logo 水印保存在手机本地。
  • 界面设置、筛选偏好和授权凭证保存在应用本地数据中；卸载或清除应用数据后可能被删除。
  • 传输目录的访问授权由 Android 系统管理，用户可在系统设置或文件选择器中撤销。
  • 授权、购买和更新功能需要互联网；授权验证会处理设备标识，支付由相应第三方支付页面处理。
