## 三、完整办理流程

`注册账号 → 实名认证 → 新建 R11 申请 → 填写申请表 → 上传材料 → 生成申请确认签章页 → 本人签名并上传 → 核对并提交 → 查看审核状态 → 下载证书`

第一次注册时，实名认证可能需要等待审核。认证通过后，从下一步继续办理。

## 四、注册和实名认证

1. 打开新用户注册链接；已有账号则直接登录。
2. 账号主体选择自然人。
3. 姓名按照身份证填写“胡钰诗”。
4. 按页面填写身份证号码、本人手机号和常用邮箱。
5. 完成短信验证和页面要求的实名认证。
6. 等待账号显示实名认证通过。

## 五、新建软件著作权申请

1. 登录登记系统。
2. 进入“软件登记”。
3. 选择 `R11 计算机软件著作权登记`。
4. 新建申请。
5. 核对申请人为“胡钰诗（自然人）”。

### 主要功能

复制填写：

> 通过 Wi-Fi 热点或 USB 连接相机；合并浏览双存储卡文件；按日期、类型、保护、连拍和传输状态筛选；提供缩略图缓存与高清预览；支持单张、连拍组和日期组队列传输；支持大文件分块及断点续传；支持无线或有线相机监看、曝光参数控制、对焦、拍照和端侧录像；支持照片边框、文字或 Logo 水印导出；支持多语言、明暗模式、免费版和高级版授权及应用更新。

### 技术特点

复制填写：

> 基于 PTP/IP 与 USB PTP 的相机通信层；串行事务调度避免命令竞态；采用大文件分块、完整性校验和断点续传；使用缩略图内存与磁盘缓存；界面采用 Jetpack Compose；提供本地签名验证的授权机制及端侧照片边框与水印渲染。
