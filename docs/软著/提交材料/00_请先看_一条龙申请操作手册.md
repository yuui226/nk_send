# Z传 V1.56 软件著作权申请操作手册

按下面的顺序操作，只需在中国版权保护中心官网提交一次申请。

## 一、准备材料

项目中已经准备好：

1. `01_Z传相机照片传输软件_V1.56_源程序.pdf`，共 60 页。
2. `02_Z传相机照片传输软件_V1.56_操作说明书.pdf`，共 8 页。

你还需要准备：

1. 本人有效身份证正面和反面的清晰照片。
2. 本人手持身份证人像面的清晰照片，用于账号实名认证。照片中本人面部、上半身和身份证信息都要清楚可见。
3. 本人正在使用的手机号和邮箱。
4. 打印机或打印店，以及可以生成清晰 PDF 扫描件的设备。

## 二、进入申请页面

1. 打开中国版权保护中心官网：<https://www.ccopyright.com.cn/>
2. 注册或登录个人账号，按页面提示上传身份证正面、反面和本人手持身份证照片，完成实名认证。
3. 进入“软件登记”。
4. 选择 `R11 计算机软件著作权登记申请`。
5. 新建申请，申请人选择本人“胡钰诗”。

正常申请全程在这个网站办理，不需要到其他网站或地点重复提交。

## 四、上传材料

按页面对应栏目上传：

1. 程序鉴别材料：`01_Z传相机照片传输软件_V1.56_源程序.pdf`。
2. 文档鉴别材料：`02_Z传相机照片传输软件_V1.56_操作说明书.pdf`。
3. 身份证明：如果申请页面单独要求上传，按页面提示上传本人有效身份证正面和反面。手持身份证照片只用于前面的账号实名认证。

上传后打开网页预览，确认源程序是 60 页、操作说明书是 8 页，并且页面能够正常显示。

## 五、签名并提交

1. 填完申请表并保存。
2. 在页面中生成并下载“申请确认签章页”。
3. 不要修改签章页的内容、格式或打印比例。
4. 使用 A4 纸、100% 比例打印。
5. 由胡钰诗本人在“申请人签章”处手写签名。
6. 将完整签章页扫描为清晰的 PDF。
7. 把扫描件上传到“申请确认签章页”栏目。
8. 再次确认软件名称、版本号和申请人无误，然后正式提交。
9. 保存申请流水号或业务编号。

## 六、提交以后

1. 登录中国版权保护中心官网查看办理状态和站内消息。
2. 收到补正通知时，在通知规定的期限内按要求修改并重新提交。
3. 审核通过后，在账号中下载并备份软件著作权登记证书。


Z传相机照片传输软件是一款运行于Android平台的数码相机影像管理工具。软件可通过相机Wi-Fi热点或USB数据线，与支持PTP/IP或USB PTP协议的尼康数码相机建立连接，读取设备及存储信息，合并展示双存储卡中的照片和视频。用户可按拍摄日期、文件类型、保护状态、连拍属性和是否已传输等条件浏览、分组及筛选文件，查看缩略图、高清预览、文件信息和EXIF拍摄参数，并进行照片切换与缩放。软件支持将单张文件、连拍组或日期组批量加入传输队列，显示任务进度、传输速度、完成状态及失败原因；针对大文件提供分块读取、完整性校验、失败重试和断点续传能力，并通过重复文件识别避免重复下载或覆盖已有文件。软件还提供相机实时监看与门、光圈、ISO及曝光补偿，执行对焦、拍照和手机端监看录像。照片传输完成后，可在保留原图的同时生成独立效果图，支持多种边框预设、拍摄信息展示、文字或Logo水印，以及字体、颜色、透明度、大小和位置设置。软件允许用户选择本地保存目录，保存传输记录和个性化配置，并提供授权激活、权益恢复、版本检查与更新等辅助功能。
