# 照片效果 LUT 独立分区

状态：代码已接入，定向编译与单元测试通过；保留在待做目录等待真机体验验收。下方分别记录实现检查和设备验证。

## 方案摘要

照片效果按“滤镜 → LUT → 边框＋水印”排列。LUT 尽量只占一行：名称拨轮、强度拨轮、收藏。照片侧独立选择目录，两个照片效果入口共享这份目录配置，与监看侧互不影响。LUT 与内置滤镜双向互斥，第一项均为关闭；边框与水印继续叠加。预览与生成共用效果规则，已入队任务保留自己的 LUT 配方。

## 1. 功能范围与目录配置

- 在照片效果中增加 LUT 功能，复用现有 `.cube` 文件读取与解析能力；不内置 LUT。
- 排列顺序：**滤镜 → LUT → 边框＋水印**。保留现有滤镜分区和操作习惯，不合并为统一滤镜选择入口。
- **照片 LUT 与监看 LUT 完全独立**：照片侧必须自行选择文件夹，不继承、不自动复用监看目录，不提供“使用监看文件夹”选项。
- 用户可以手动选择同一个文件夹，但两侧更换目录、开启、关闭和选中状态互不影响。
- 照片效果的两个入口共用照片 LUT 文件夹，不各自设置第三套目录。效果草稿、确认与保存继续遵循两个入口各自既有规则，不因共享目录而擅自同步全部编辑状态。

## 2. 单行布局

尽量沿用当前滤镜行的高度、材质、圆角、按钮及触感反馈，文件夹入口集成在名称拨轮中；不另占一行放标题或设置按钮。

```text
[ LUT 名称拨轮（最宽） ] [ 强度拨轮 ] [ ☆ ]
```

- 名称拨轮分配最多宽度；强度拨轮紧凑，收藏为图标按钮。
- 未设置目录时，点击名称拨轮中的“设置LUT文件目录”选择目录；设置后长按拨轮更换目录。无独立文件夹按钮或额外设置窗。
- 触感反馈遵循全局设置，不新增独立震动开关。
- 优先保持单行，不为了容纳名称增高整个分区；窄屏与大字体下的尺寸边界在实现时核对，不能靠缩小触控区域或遮挡相邻控件硬塞。

## 3. 名称拨轮

- 第一项固定为“关闭”，后面为当前文件夹中的可选 LUT。
- 隐藏 `.cube` 后缀，不修改真实文件名。
- 短名称使用正常字号；长名称允许两行，必要时适度缩小字号，仍放不下则省略。设置最低可读字号，不无限缩小。
- 所有选项槽位高度相同，两行文字不能改变某一项的高度或破坏滚动吸附。
- 复用现有拨轮松手提交及触感机制，不在滑过每个选项时反复读取、解析和生成预览。
- 最新要求：LUT 拨轮长按用于更换文件夹，不打开完整名称选择弹窗。
- 文件身份不只依赖名称；同名文件不能合并成一个选项，必要时使用简短的区分标记，不能依赖不存在的长按列表。

## 4. 与内置滤镜互斥

| 操作 | 结果 |
| --- | --- |
| 成功启用 LUT | LUT 生效，内置滤镜拨轮回到第一项“关闭” |
| 启用内置滤镜 | 内置滤镜生效，LUT 拨轮回到第一项“关闭”，取消尚未完成的 LUT 加载 |
| 关闭 LUT | 关闭 LUT，不自动恢复之前的内置滤镜 |
| 关闭内置滤镜 | 关闭滤镜，不自动恢复之前的 LUT |
| LUT 加载失败 | 不提交新效果，保留先前可用效果；初次从滤镜切入失败时 LUT 保持“关闭”，原滤镜保留 |

- 互斥只关闭当前效果，不清空各效果记住的强度与收藏，不影响边框、水印。
- 从一个有效 LUT 切换到另一个 LUT 失败时，保留原 LUT，不突然变成无效果。
- 迟到的加载、预览结果不能重新打开已关闭的 LUT，也不能覆盖用户后来选择的滤镜。
- 加载反馈保持轻量，不插入额外高度或打断整行布局；具体动画在实现时沿用项目公共规则。

## 5. 强度与收藏

- 支持强度调节，默认 100%，表示原照片与 LUT 处理结果的混合程度。
- 沿用现有滤镜强度拨轮的档位习惯，每个 LUT 独立记住强度；切换时不套用上一款效果的强度。
- LUT 关闭或没有可用文件时，强度与收藏置灰且不可操作。
- 收藏项排在“关闭”之后，不在列表中重复出现；其余文件按稳定顺序排列。
- 收藏按文件身份记录，不以同名作为同一文件；不可用的旧文件不能作为当前目录的可选项继续展示。

## 6. 文件夹与空状态

| 状态／操作 | 展示与行为 |
| --- | --- |
| 尚未选择照片 LUT 目录 | 名称区域显示“设置LUT文件目录”；点击即可选择，强度与收藏置灰 |
| 目录存在但没有 `.cube` | 显示“未找到 .cube 文件”，点击名称区域或长按拨轮可更换目录，不显示无意义的空拨轮 |
| 目录不存在或授权失效 | 与空目录区分，简短提示并允许重新选择 |
| 取消选择目录 | 保持原目录、效果和选中状态 |
| 新目录读取失败 | 保留原有可用配置，不以失败结果覆盖 |

目录扫描、解析和后台读取队列复用监看侧实现，配置分开。进入 LUT 分区时重新扫描目录元数据；成功更换目录清空本入口当前 LUT，删除或失去权限的文件不再作为可选项。当前效果使用已加载快照，外部修改文件不会悄悄改变当前效果；关闭后重新选中该文件时读取新内容。另一照片入口下次打开时按共享目录刷新。以上变化均不改变已入队配方。

若用户手动让照片与监看选择同一个目录，更换任一侧目录时保留另一侧仍在使用的读权限。

## 7. 照片处理与任务约束

以下为实现采用的技术边界：

- 处理顺序：**原图／裁切图 → LUT 或内置滤镜 → 边框 → 水印**。LUT 不染色边框、文字、品牌标志或水印。
- LUT 写入生成的效果图，不修改原文件；既有原图、裁切图及效果图保存规则不变。
- 遵循照片效果总开关：关闭时按现有规则跳过生成，不清空 LUT 配置，也不禁止编辑器预览。
- 队列保存入队时的效果配方。只保存外部文件 URI 不足以保证效果稳定，应保留所需 LUT 内容的内部快照，同一内容可复用，任务结束后按引用情况清理。
- 后续更换目录、关闭效果、删除或修改外部 LUT，不能悄悄改变已入队任务的配方；总开关跳过生成仍按既有规则处理。
- AP、STA、USB 的相机传输任务及本地照片效果入口共用照片处理能力，不在各连接协议里分别实现 LUT。
- 可复用监看侧文件管理和解析，但监看 GPU 显示不等同于高分辨率导出。需单独设计导出资源管理，确保预览与输出的颜色、强度一致，避免原图尺寸的多份像素副本与重复解析。
- `.cube` 扩展名不能识别用途：普通照片不能自动当作 N-Log 输入，不根据相机品牌自动套 Log 还原，也不承诺任何 LUT 都适用于照片。
