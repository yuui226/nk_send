# iOS 列表滚动与预览效果窗复核

2026-10-18，用户要求改善列表滚动和预览动画卡顿；修正预览照片效果按钮，移除底部系统抽屉，复用照片效果弹窗，返回时直接回到当前预览。基准为本地 android `9d7dd882`：`FileListScreen.kt`、`PhotoPreview.kt`、`SettingsScreen.kt`、`AnchorPopup.kt`，以及既有预览/列表专项测试。此次局部样式、动画与交互明确在用户授权范围内。

## 开发任务

1. 列表高频更新：原可见格子、滚动项、日期入队按钮坐标每帧写回页面 `@State`，导致重新执行日期/连拍分组与子视图构造。改为页面持有的非发布几何缓存；交互始终读取最新坐标快照，仅到顶状态发生变化时更新UI。保留返回定位、入队飞行动画与回到顶部阈值。遥控提示的 `collapse()` 仅在确实展开时发布，消除拖动/减速期间反复发布同一个false。
2. 预览渲染：精确翻页偏移保存在独立对象，仅文字/直方图淡化修饰器观察它；当前页仅在跨页阈值变化时发布，父层仍读取最新偏移判定手势。FHD替换淡化保留300ms FastOutSlowIn曲线，改为渲染事务，移除16ms循环写状态带来的整套图片/手势视图重算。原340ms入场后开始远端读取的规则保留。
3. 效果入口：按安卓使用橙色AutoAwesome形状、20pt图标/44pt按钮、`photo_effects_open_editor`文案和触感；仍仅总开关开启、非回看JPEG显示，拒绝动画/传输入队期间的再次进入。
4. 共享效果窗：直接复用 `SettingsPopupOverlay` + `SettingsView(effectsOnly:true)`，删除独立sheet/草稿路径；同步当前预览的图片、FHD升级、EXIF和旋转，不另取最新照片或额外请求相机。主设置/预览共享滤镜、LUT、边框、水印、收藏、导入、说明与持久化。首次已呈现挂载也初始化草稿；原首次只依靠onChange的路径不再漏初始化。返回和点外部先提交，等关闭动画结束才释放请求；关闭期间继续屏蔽底下翻页/入队手势，随后回到原预览。

## 动画依据

安卓预览 effectsOnly 使用屏幕安全区域内左右12、上下8的面板，`gentleMotion` 为260ms展开/220ms收起、FastOutSlowIn，opacity=p、scale=.94+.06p，围绕入口按钮位置缩放。iOS复用原生弹窗宿主，以单个live layer执行这组参数，不为此创建网格截图或逐帧重建SwiftUI。主设置原来的Genie变形路径保持，关闭反向从当前进度开始。
