# 预览上滑方向锁定与渲染

日期：2026-10-20。用户要求上滑后禁止同次触摸左右翻页，并优化上滑动画卡顿。主代理独立处理；真机留给用户稍后测试，不安装、不提交或推送。

## 行为依据

安卓基准：本地 `android` 的 `25860ae6`，`PhotoPreview.kt` 1070–1157 行及 `PhotoPreviewQueueGestureTest.kt`。越过方向门槛后保持 UPWARD，消费后续指针变化，禁止 HorizontalPager 滚动，结束/取消后恢复；横向和下滑先胜出时不转为入队。保留 iOS 已有 8pt 识别门槛、1.15 倍方向比例、96pt 入队门槛、0.22 阻力、1.24 倍上限、0.055 缩放和 0.07 透明度变化，以及 105/155ms 抛起、原弹簧和飞行时序。

## 发现与修复

- 新增真实触摸回归：以 200pt/s 斜向上滑 `(-130,-220)`。修改前 74 个移动事件先判为 upward，随后原生分页器横移到约 -0.30 页；页偏移超过 0.01 后把已经锁定的上滑改成 rejected，最终没有入队。此前只测纯竖向上滑，不能证明斜向和方向锁定完整，此证据缺口已纠正。
- `PageTabView` 的 `.scrollDisabled` 在此结构中没有可靠禁用内部 UIScrollView。利用现有分页观察器定位实际分页器，方向确定时同步禁用它的 pan recognizer，并收回识别前极小的横向偏移；不移除预览的命中子树、不取消正在跟踪的上滑。锁定后不再依据页偏移重新拒绝上滑。手指释放、取消与页面卸载均还原原来的 pan enabled 值；不会打开原本被其他条件禁用的 pan。
- 同页同偏移不再重复通知；布局测量只在标记本地 frame 改变时重发，普通缩放/抬起不触发重复测量；原有 contentOffset 观察、尺寸变化、页面重用、弱引用与卸载清理保留。没有新增持续帧钟、图片解码或图片副本。
- 实际稳定拖动区间，修改前 70 次分页通知、1 次预览父 body、296 次测试图片矩形回调；修改后对应为 **0、0、120**。减少的矩形回调含被错误带入的相邻页，不能把该比例解读为帧率或 CPU 降幅。初始怀疑“整页逐帧重建”未获证据支持，没有据此重写渲染架构。图片跟随仍由独立 motion 叶节点更新。
