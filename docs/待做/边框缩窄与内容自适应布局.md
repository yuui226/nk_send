# 边框宽度与统一内容布局

状态：统一布局已接入，自动校验完成。2026-10-01。

## 当前要求

- 两处边框设置共用 60%～200%、每档 10%、默认 100%；两处各自保留配置。
- 每个模板只有一套内容布局，覆盖整个宽度范围。100%不是切换算法、字体或对齐方式的边界。
- 以原模板的字体、信息层级和装饰风格为依据。宽度调节主要收放空白，不改变原照片像素、方向及裁切。
- 信息少时释放空间，信息多时保留必要区域，不裁字、不自动隐藏字段、不无限缩小字号。
- 沉浸无外框，不参与这套宽度调节，保留既有行为。

## 旧方案的问题与替代

旧方案把低于100%作为独立绘制路径，造成品牌内嵌字体改变、雾白与色彩档案行距增大、铭牌水印位置改变。逐个补丁不能根治，已取消宽度条件分支和旧文字绘制分支。

当前预览和原尺寸导出均调用 `calculateMeasuredFrame`，它按模板分工，不按宽度分两套算法。最终布局由 `MeasuredFrameTextPlan` 或参数海报的测量结果表达，绘制端不重新换行或缩字。

## 简单、可维护的规则

1. 复用已准备的展示元数据和水印设置，确定信息属于照片内还是边框内。
2. 在照片宽1000单位的设计坐标中，用实际字形和Logo测量内容。每模板明确分区、字体、对齐、间距、必要装饰尺寸。
3. 边距随宽度变化，受到内容与装饰的最小需求约束。字号保持稳定；组内间距只允许收紧到设定下限，加宽后不持续撑大。
4. 图内信息不受外框宽度控制，字体、行距、水印避让在全部档位使用同一逻辑。
5. 长文字只在指定区域按Unicode/单词边界换行。参数保持语义分组；水印保留用户尺寸及显式位置选择。
6. 内容测量完成后决定画布、检查尺寸和内存，再分配位图。分区解码和整图渲染使用相同布局。

不增加通用约束求解器、循环试排、布局缓存或新的状态系统。不增加相机、EXIF、地理查询，不在动画帧中计算布局，不创建额外完整原片副本。

### 连续性的边界

尺寸和位置连续收放，整数像素取整允许1像素变化。换行本身是离散行为，只在文字确实跨过容纳边界时发生；不能承诺任意长度的文字完全不换行。内容达到必要尺寸后，继续减小拨轮值可以不再压缩该区域。

“60%”表示期望边距比例，不承诺四边和所有信息区域严格缩成60%。保存的值不会被内容下限反写，也不动态增删拨轮选项。

## 各模板规则

| 模板 | 信息与宽度规则 |
| --- | --- |
| 雾白、暗夜、简白 | 品牌/型号、镜头、参数时间、地点、署名保留层级；默认字体稳定，行距不把收回的留白重新分配出去 |
| 毛玻璃 | 共用常规信息布局；面板左右与照片对齐，不随外画布扩宽；文字在照片宽度的左右各6%内边距内排版，面板保留安全内边距和圆角 |
| 铭牌 | 左右列独立测量；品牌/型号及AUTO、左侧文字水印组成左列，按可见字形统一行距；右侧行数不推开左列；手动中/右水印仍按原位置独立排放 |
| 品牌内嵌 | 图内品牌使用原品牌字体，详情复用原粗斜体；按字形计算行距，不把阴影余量加在每行之间；外框不控制图内排版 |
| 品牌留白 | 图内信息独立于外框；框外品牌保持层级；AUTO水印留在照片内，手动框外文字水印仍在品牌上方 |
| 经典签名 | 斜体标题与下方说明分别测量，标题不因宽度跨100%改变字体 |
| 艺术装裱 | 维持方形、内框和照片安全距离；结构性留白不当成空信息删除 |
| 色彩档案 | 文字与色块分区；品牌和曝光保留粗体；行距沿用信息带比例规则并有限收紧，去掉缩窄分支额外标题间距 |
| 胶片画廊 | 保留齿孔和条带；品牌/日期先测量，过长时进入信息区；装饰绘制不再重复画信息 |
| 胶片边框 | 保留侧字和紧凑说明风格，侧字在边带居中；所有宽度采用同一字体和排版 |
| 参数海报 | 保留竖图侧栏、横图底部两列及参数标牌；一份测量结果绘制；无信息时释放侧栏，长信息按区域扩展 |
| 沉浸 | 不改，不新增宽度 |

## 数据与输出

- 拨轮范围、序列化、收藏、任务快照、两处设置和输出身份均支持低档位。
- 新统一布局使用 `measured-layout-v=4` 区分输出身份，毛玻璃面板对齐修正追加 `glass-panel-v=2`，避免误复用旧布局成片。
- 原图保存、裁切顺序、滤镜/LUT、专业版权限和照片效果总开关逻辑不变。
- 图内水印与框外水印各走一次，不重复绘制。
- 超出合法尺寸或确实无法避让的极端组合应返回明确错误，不用裁剪掩盖重叠。
