# 预览无损裁切传输

状态：按 2026-09-26 最新需求修正实现。基线提交 178b9b8f。界面体验由用户验收，不运行模拟器交互测试。

## 最终流程

1. 用户在大图预览点击裁切，复用当前 FHD；正在加载则等待同一请求，不重复取图，不预取原图。
2. 从已有 EXIF 复用照片方向；缺少时仅补读有界 EXIF，遇相机忙最多重试两次。不要求此时拿到原图尺寸、SOF、MCU 或完整原图头。
3. 排除 FHD 成对对称的近黑填充边，统一坐标方向；屏幕上的 FHD 保持原来的方向、位置、缩放，不为进入裁切而旋转或重绘。相机 EXIF 方向与用户手动预览旋转只参与坐标换算。
4. 用户框选后，保存有效照片区域内的归一化矩形、方向和固定比例，独立加入队列。
5. 原文件下载到私有临时目录后，才读取真实尺寸/采样/方向，把比例坐标映射到原图并进行 JPEG MCU 边界对齐及无损裁切。
6. 保存无损裁切 JPEG；如需照片效果，引用已保存的裁切图另存效果图。清理未裁切原片和私有临时文件。

旧方案中“进入编辑前必须确认原图完整几何信息”的限制已移除。此限制把多种准备失败合并成“无法确认完整画面”，导致用户在 STA 下无法进入裁切。新的失败提示分别说明 FHD、方向或连接问题。

## 原地编辑交互

- 保留现有预览背景与页面，不再覆盖一个独立底色、标题栏的编辑页面。
- 只淡入淡出工具、参数、遮罩与裁切框；FHD 保留原来的渲染节点和纹理。裁切初始框采用当前实际图片位置，包括此前的缩放与平移，不重新适配图片区。
- 自由、原比例、1:1、3:2、4:3、5:4、16:9、2:1；比例按钮按空间换行，常规手机两行，不横向滚动。
- 对号在右下角；底部根据现有传输队列按钮实际位置保留距离，不覆盖队列入口。
- 取消、重置、横竖比例互换使用图标；沿用触感设置。支持单指平移、双指缩放、四角调整，不能露白。
- 编辑期间禁止原预览翻页、上滑入队及图片点击关闭；系统返回先取消裁切。
- 原图确认和 JPEG 编码块吸附发生在下载后，因此最终边界可能有极小像素调整；不能再称预览时已吸附至原图编码块。

## 队列与无损规则

- 仅 JPG/JPEG；RAW、视频不提供裁切入口。
- 独立任务保存裁切与照片效果快照，剪刀标记贯穿各状态，失败重试保留选择。
- AP、STA、USB 共用现有下载及统一后处理，普通任务路径不变。
- 无效果使用 JPEG 系数裁切，不重新量化、不转 PNG；有滤镜/边框/水印时走现有重新编码流程。
- 关闭照片效果总开关仅跳过效果，不取消裁切；未裁切原片不发布，无损裁切图始终保存。相机原图及手机原有照片不改变。
- 原图实际 EXIF 方向与选择时不一致则失败，不静默套用错误方向。
- 失败不得变成成功或退而保存未裁切图。正常与异常清理临时文件；遗留私有会话目录启动时清理。
- 运行任务沿用完成当前张的规则，等待任务允许撤回。

## 性能与检查

- 编辑只借用已有 FHD，不创建旋转/裁边位图副本，不回收预览缓存拥有的位图。方向和填充边只以坐标描述。
- 无 JPEG 原图解码；下载后以有界文件头和原生系数裁切处理，限制输入、像素和系数内存。保留 ICC、拍摄 EXIF，去除旧缩略图。
- 下载后的几何解析只执行一次；共享处理额度避免同时堆积大图处理。
- 普通 FHD 获取顺序不变，撤回此前临时添加的“优先 MPF”分支，不改变 AP/STA/USB 普通预览策略。
- 针对性 JVM 测试通过：归一化选择映射到不同原图尺寸和八方向、固定比例、方向不符拒绝、仅 EXIF 即可读方向、对称填充边识别及全黑照片保护；原有裁切几何测试同步通过。
- 本轮只进行代码审查、编译和 JVM 测试，不运行模拟器、不安装 APK。

## 验收边界

需要用户实际确认不同机型返回的 FHD 方向与填充边形态，尤其是倒拍、竖拍与机内特殊裁幅。已有模拟器历史验证不能替代该检查；本轮不会声称已验证所有 Nikon 机型。无损 JPEG 边缘的解码插值可能与原图不同，但不新增 JPEG 量化损失。

## 2026-09-26 原位体验修正

- 图片视口状态在预览与裁切之间共享；进入时没有图片透明度变化、重新缩放、重新居中或底色切换。
- 手势仅在用户操作后调整共享图片视口；取消或确认时恢复进入前的缩放和平移，必要时以 180 ms 动画恢复。
- 取消/确认通过原预览按钮层淡入与裁切按钮层淡出完成。底图仍是完整 FHD，不能用裁切结果替换。
- 确认成功入队后，以裁切区域绘制飞行残影，复用现有入队时序、曲线和队列接收反馈；普通照片不上抛。飞行只裁剪绘制共享 FHD 纹理，不分配裁切位图。
- 入队被目录/连接校验拒绝时不关闭编辑、不播放成功动画；动画超时和取消沿用原有状态复位与计数清理。
- 普通预览旋转与真实 EXIF 方向分别映射，保证“当前看到的框”与下载后的裁切选择一致；方向校正不再改变编辑画面本身。
- 编译及 17 项相关 JVM 测试通过，覆盖原位初始化、已缩放视口、比例选择、重置、预览旋转映射及原有队列手势。本轮仍未运行模拟器或重新打包。

## 竖向比例、按钮与预览会话修正

- 新增显式 2:3、3:4、4:5、9:16；保留原有横向比例与方向切换，点击明确比例不会继承上一档的反转状态。
- 连续切换比例使用同一选框尺寸基准，不再以内缩后的框继续内缩；手动改框后更新基准。切换只改变框，不改变照片位置或缩放。
- 参考 Lightroom 的方向切换说明和 uCrop OverlayView 的独立可用区域计算；本项目额外保留用户手动选框的基准尺寸。
  - https://helpx.adobe.com/lightroom/mobile/crop-and-transform/crop-photos.html
  - https://github.com/Yalantis/uCrop/blob/develop/ucrop/src/main/java/com/yalantis/ucrop/view/OverlayView.java
- 翻页到 RAW、视频等不支持裁切的对象时，裁切按钮淡出并收起；返回 JPEG 时淡入展开。退出动画中点击不会误给不可裁切文件创建任务。
- 对号复用 GlassButton 的主题材质与按压反馈，不再使用独立蓝色实心底。
- 连续极端缩放/改框可能使区域小于固定比例最小整数像素单元，现限制缩放上限，避免交互时抛异常。
- 用户明确复现路径是“大图预览 → 队列 → 返回后长按另一张”。FilesQueueWorkspace 使用 SaveableStateProvider，预览原先的 rememberPagerState 会恢复旧页码并覆盖新 initialIndex。已改为仅当前组合期间持有的 PagerState，预览页码不再随工作区保存；列表滚动恢复不变。
- 每次主动打开仍以独立会话 key 初始化，旧会话关闭回调不能关闭新预览，覆盖快速连续打开的边缘情况。
- 比例与坐标、原位视口、预览入队手势共 16 项 JVM 测试通过；最后的非保存分页状态修改另做编译检查。没有运行模拟器、打包或安装。

### 裁切入口应用真实方向（2026-09-26）
- 先前真实方向只参与坐标换算，未应用到照片显示。现在进入裁切时将已有 FHD 按解析出的方向转正，沿用预览旋转动画，待方向与布局就绪后启用选框。
- 选框、入队缩略动画和最终裁切使用同一显示方向；不新增图片下载或位图解码。退出裁切保留已校正的方向，不转回原方向；仅恢复裁切手势前的缩放和位置（发生方向校正时为转正后的完整视图），不修改全局旋转偏好。
- 镜像 EXIF 方向暂不支持在此视图正确呈现，明确走方向不可确认提示，不以纯旋转代替镜像。
- 比例选择分为横向五项、竖向五项（含 1:2）、通用三项；独立圆角底色及描边。左上只保留关闭，移除重置、横竖互换入口。

## 裁切原图与效果图分别保存

- 裁切任务以无损裁切图替代原图，保存到任务对应的照片目录；效果图仍存入该目录的 ZTFrames。
- 效果导出读取已保存的裁切图，不读取未裁切原片。关闭效果时仅保存裁切图。
- 效果失败保留已经保存的裁切图；同一任务重试时，目标目录未变且文件仍可读则复用，避免重复保存裁切图。
- 未裁切下载原片与工作缓存继续清理；普通非裁切任务流程不变。

## 保存规则更新：保留原图

本节取代前述“不发布未裁切原片”的规则：
- 原图按相机文件名保存，方便用户日后重新裁切。已有同名、同尺寸且可读的原图沿用原文件。
- 裁切图命名为 `原图名_crop.jpg`（所有语言统一使用英文后缀）；不同裁切遇到重名时附加序号，避免覆盖。
- 效果图继续读取已保存的裁切图生成并保存到 ZTFrames。
- 清理只针对私有工作缓存；原图与裁切图不因效果失败被删除。

## 裁切返回后的手势恢复

- 裁切退出回位捕获当前视口及目标值，正常完成或超时取消均在 finally 恢复状态，手势不再依赖淡出透明度精确归零。
- 普通照片翻页直接读取当前视口的缩放状态；手势处理器绑定视口实例，避免预载页转为当前页后仍操作旧状态。
- 上滑识别退出与取消统一释放拖动状态；无法识别上滑时不抢占缩放、平移和分页事件。
- 编译及 PhotoPreviewQueueGestureTest、CropEditorGeometryTest、PreviewCropPlacementTest 通过；未进行模拟器交互验证。

## 正常预览与裁切布局分离

- 正常预览在顶部信息与底部工具栏之间等比居中；不再固定贴近顶部。
- 裁切布局在队列按钮下方预留竖图 20dp / 横图 80dp，并为三行比例选项留空间，空间不足等比缩小。
- 底部操作区距导航安全区上方 32dp，加号与第三行对号保持同一位置。
- 进入裁切用 220ms 过渡至完整适配画面，上移完成后再初始化选框；退出恢复进入前缩放与位置，已校正方向保持。
- 过渡有超时收尾，手势在恢复完成后启用；显示位置与裁切坐标使用同一套布局计算。
