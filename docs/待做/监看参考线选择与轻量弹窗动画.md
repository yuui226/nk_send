## 全局复用前的性能检查

2026-09-26：完成不改变外观的优化。

- 变形矩阵及行数组由绘制缓存复用，不再每帧为每个三角形分配 Matrix / FloatArray；边界在生成行时一次汇总。
- 向上展开的镜像坐标每帧只转换一次，不再每条带重复转换。
- 避免有效变形路径每帧往返切换 SrcOver / Plus；仍保留必要的整层合成以消除三角形接缝。
- 绘制缓存重建或面板尺寸变化时使旧录制失效，防止异步选项加载后沿用旧尺寸图层。
- 曲线、320ms 展开 / 350ms 收回、12条带（后段6条）不变。稳定展开时直接绘制，不持续做网格变形。无 Bitmap 回读，无逐帧 Compose 尺寸动画。
- 剩余主要 GPU 成本：过渡期每帧最多24次裁剪图层绘制和一次中间合成；代码检查不能证明所有设备无掉帧，需后续真机帧耗时测量再决定是否降低网格精度。
- 可作为按钮锚定菜单的共用动效基础；不建议直接推广到照片预览等大面积/持续变化内容，也尚未批量迁移全局菜单。
- 编译及上下方向几何、复用矩阵顶点映射测试通过；未运行模拟器、未进行实机性能基准。
