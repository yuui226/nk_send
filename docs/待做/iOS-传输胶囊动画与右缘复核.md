# iOS 传输胶囊动画与右缘复核

基准：本地 android 分支 `9d7dd882`，`FileListScreen.kt` 的 `AnimatedQueuePillCount`、`QueuePill`，以及 `QueuePillStateTest.kt`。用户于 2026-10-18 要求数字滚动、固定右缘及各状态平滑衔接。

## 规则与改动

- 数量减少时旧数向上离开、新数从下方进入；增加时反向。位移为整数像素半行高；进入淡化 160ms，退出 120ms，位移沿用安卓临界阻尼刚度 400 弹簧。连续变化保留尚未退完的数字，反向复用已有数字层。
- iOS 已有上述纯动画模型，但渲染时钟原先依赖隐藏文字的 Preference 高度才建立；未建立时更新仅改变静态后备文字。本轮取消该启动前提，依据现有 labelLarge 的 20pt 行高建立时钟及裁剪框，挂载时应用屏幕像素密度。卸载停止时钟。
- 顶部右侧控件改为独立 trailing overlay，避免与左侧按钮总宽度争用 HStack 导致整体向右溢出。胶囊布局限制到可用宽度，并从右上角放置可见内容；内层自然内容仍靠右，宽度弹簧仍由原模型控制。
- 图标与文字胶囊改为同一个 Button、同一个内容转场实例，避免模式变化销毁退场内容和数字时钟。保留模式进入 220ms／延迟 35ms、退出 160ms 的交叉淡化，旧数量／速度保持各自快照。液态玻璃材质持续存在，物理主题图标仍使用原主题材质。
- 速度数字沿用既有数值过渡；同一模式速度样本不重启模式淡化。宽度继续沿用已有测量分类、像素取整、弹簧和中途重定向，未增加持续空闲刷新。
