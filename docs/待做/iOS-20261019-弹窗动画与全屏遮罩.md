## 行为基准和实现

- 安卓 `HomeScreen.ResetStaPairingDialog`、`SettingsScreen.GpsResetPairingDialog`、`PhotoLutEditor`/滤镜选择以及 `PurchaseDialog` 使用 Compose `Dialog`。`themes.xml` 继承 `android:Theme.Material.NoActionBar`；本机 Compose UI 1.7.6 AAR 中 `DialogWindowTheme` 未替换窗口动画。沿 Material Dialog 的系统窗口动画，内容进入为 +20dp → 0、220ms、standard(0.2,0,0,1)，退出为 0 → -10dp、150ms、standard_accelerate(0.3,0,1,1)，同时淡入/淡出。系统版本的默认动画可能变化，本次按 AOSP Android 15 固定资源实现，不用 iOS 默认动画替代。
- 新 `AndroidDialogPresentation` 保留退出期间的内容和触摸边界；快速反向从当前可见值继续。`AndroidDialogClock` 只在有限动画期间刷新，结束/卸载停钟，复用已有弱目标 DisplayLink 和 Bezier 求解器。只有表层与遮罩观察每帧值，不让整个列表/表单随动画重建。
- STA 按本次用户明确要求使用**透明外部点击区域，不压暗背景**。这是相对安卓 Dialog 默认压暗的明确批准差异；外部点击关闭、确认后重置全部 STA 配对、取消与保留无线模式等业务不变。GPS 及原本需要压暗的弹窗继续保留遮罩。
- 两个照片效果入口的滤镜/LUT 选择共用上述实现；购买沿原有 Apple 权益逻辑。没有移植安卓购买后端，也没有恢复监看端侧录制。
- 安卓 `PhotoEffectModuleMenu.kt` 使用 `AnchorPopup(dim=false)`。iOS 原来用条件分支直接插入菜单，补为现有 Genie 原生宿主，320ms 展开/350ms 收起，沿 `GeniePopupMotion` 曲线与锚点形变。保持透明、四模块切换及独立草稿，右侧按安卓保留18pt；收起结束后移除，关闭中重开复用同一宿主。
- 白条根因：连接页/工作台的 `UIScrollView` 翻页容器本身只覆盖安全区，子视图 `ignoresSafeArea` 仍被父滚动容器裁掉。现在容器覆盖整个窗口，再向内容传入固定安全区间距；上、下页滚动时不使用不断变化的 UIKit 子控制器安全区。iOS 16.4+ 关闭子 hosting 自动安全区，保留父 SwiftUI 传入的实际间距（含键盘变化），避免重复扣减；更早系统保留 UIKit 原有处理。

系统动画依据：[Material Dialog 样式](https://raw.githubusercontent.com/aosp-mirror/platform_frameworks_base/android-15.0.0_r1/core/res/res/values/styles_material.xml)、[进入](https://raw.githubusercontent.com/aosp-mirror/platform_frameworks_base/android-15.0.0_r1/core/res/res/anim/popup_enter_material.xml)、[退出](https://raw.githubusercontent.com/aosp-mirror/platform_frameworks_base/android-15.0.0_r1/core/res/res/anim/popup_exit_material.xml)、[位移值](https://raw.githubusercontent.com/aosp-mirror/platform_frameworks_base/android-15.0.0_r1/core/res/res/values/dimens.xml)、[standard](https://raw.githubusercontent.com/aosp-mirror/platform_frameworks_base/android-15.0.0_r1/core/res/res/interpolator/standard.xml)、[standard_accelerate](https://raw.githubusercontent.com/aosp-mirror/platform_frameworks_base/android-15.0.0_r1/core/res/res/interpolator/standard_accelerate.xml)。
