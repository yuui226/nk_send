# 全局触感反馈梳理与优化方案

2026-09-26。调查基于提交 88473510；本文为设计建议，尚未实施批量修改。

编号说明：A 为现状与风险，B 为具体场景，C 为统一设计规则，D 为实施顺序。可直接用编号选择，例如“B03 要，B20 不要”。编号仅用于讨论，不代表已批准实施。

## 现有基础与明确发现

- **A01** ui/util/Haptics.kt 集中提供 tick、longPress、success、failure 和 GPS 长按蓄力。普通反馈使用 Android 系统常量；自定义蓄力直接使用 Vibrator。
- **A02** 当前 tick 同时用于开关、拨轮、入队、开始操作等不同语义，尚无应用层频率控制。
- **A03** HomeScreen：STA 连接点击已补 tick；连接结果已有成功/失败反馈。
- **A04** FileListScreen / PhotoPreview：预览、入队、裁切操作已有反馈，整组入队一次，队列实际完成一次，跳过/取消不庆祝。
- **A05** RemoteScreen：参数变更、半按/点按对焦、拍照、相机录像、端侧录像保存已有不同程度反馈。TopIconToggle / GlassButton 本身不统一添加震动；工具栏切换、相机选择菜单、参考线选择、工具编辑未建立完整反馈规则。
- **A06** SettingsScreen / ReleaseCommitWheel：大量参数、布尔设置按档位触发 tick；照片效果与本地效果共用控件。触感开关自身目前使用 hapticsEnabled || isHapticsPreference，关闭时操作该开关仍有反馈，这是特例，需要明确产品规则。
- **A07** GPS 长按 800ms 使用十段逐渐增强的脉冲并在确认时补重点击。未检查幅度控制能力；没有显式触摸用途属性。不能仅凭普通 performHapticFeedback 的行为，声称这条直接 Vibrator 路径也完全遵循系统触摸震动设置。
- **A08** 缩略图 combinedClickable 没有显式关闭内建长按触感，同时 onPreview 会触发 longPress。应核对实际 Compose 版本默认行为，排除重复震动和绕过 App 开关；这是待核实风险，不是已经测到的双震。
- **A09** Android 旧版 failure 的第二次 tick 延迟65ms，回调只检查 View 是否挂载，不重新检查最新 App 开关。自定义蓄力取消受旧 enabled 实例影响，也需要生命周期清理。
- **A10** FireworksOverlay 按每个烟花爆点 tick，属于装饰性触感，应降低优先级并避免与业务成功重复。

| B15 | 裁切入口/比例/确认入队 | 已有tick | 比例变化轻点，确认以成功入队为准；缩放、移动、拖角不持续震 |
| B16 | 队列开始/暂停、重试、清空、单项取消 | 开始/暂停已有，其余需统一 | 执行动作一次，打开确认卡不播放成功；失败用短拒绝感 |
| B17 | 传输/生成完成 | 队列胶囊已有过滤 | 保留整批一次，不逐文件震；实时传输连续小批完成需合并；取消/全部跳过不庆祝 |
| B18 | GPS开关、长按关闭/重置、坐标查询/复制 | 有开关与蓄力 | 保留有意义反馈，提前松手立即停止，退出页面/关闭触感开关也停止；后台GPS刷新静默 |
| B19 | 激活、续费、购买结果 | 没有统一接入Haptics | 真正成功才确认一次，不按轮询震；失败仅面向当前用户操作 |
| B20 | 烟花等装饰 | 每个爆点tick | 降低频率，不叠加业务成功，不抢占操作触感 |

## 统一设计建议

- **C01** 细刻度：拨轮、拖动换槽、离散吸附。强度最低；以状态变化触发，限制密集连续事件，不补发积压震动。
- **C02** 轻点击：开关、菜单选择、开始动作、有效入队。短促一次；同值/禁用/重复点击无反馈。
- **C03** 拿起/确认长按：进入预览、开始拖动等明确手势成立的瞬间，不在按下和松开重复播放。
- **C04** 成功：连接完成、实际保存、整批完成。较明确但仍短促；与刚发生的轻点击适当合并。
- **C05** 失败：明确失败时一次短拒绝反馈，自动重试、轮询失败不刷震动。

- **C06** 优先使用设备调校的系统触感，不用固定高幅度波形来模拟所有手机；硬件不支持细腻反馈时回退为更简单、克制的效果。遵循 App 触感开关与系统触摸反馈偏好。主线程只提交反馈，不进行等待。

- **C07** 默认保留开关自身“开启时立即体验一次”的能力；建议关闭后静默，关闭状态滑动经过开关不连续预演。此产品规则需确认后再实施。

## 实施顺序

- **D01** 第一批：开关覆盖与生命周期取消、默认长按重复风险、旧版延迟回调、无幅度控制设备蓄力回退。
- **D02** 第二批：菜单/小工具/拖动排序/队列操作的缺口，区分点击与长按预览，清除同次操作重复来源。
- **D03** 第三批：拨轮刻度限频、连续自动传输结果合并、低优先级装饰反馈。
- **D04** 最后在不同马达设备上校准。代码检查能保证时机和次数，不能保证所有手机同样细腻。

## 2026-09-28：统一长按触感（本次已接入）

用户要求所有长按复用 GPS 关闭的触感。本次采用完整渐强波形＋触发确认，不改变每个动作已有触发时长；GPS 800ms 波形保持原样，普通控件跟随系统长按阈值，快门半按对焦保留 300ms。

1. GPS 长按关闭：保留原波形与确认。
2. GPS 标题长按复制诊断：通过共用拨轮接入。
3. 滤镜拨轮长按分类列表：两个照片入口共用。
4. LUT 拨轮长按更换目录：两个照片入口共用。
5. 照片格子长按预览／入队：保留用户配置的短按、长按动作分工。
6. 连拍合集长按预览。
7. 照片效果长按对比：只在对比帧可用时提供反馈。
8. 快门长按半按对焦：快拍不额外等待，拍摄确认仍是独立阶段。
9. Debug 模拟入口长按。

共用长按反馈器只负责触感，不重写原来的手势识别。提前松手、滚动接管、页面退出或触感开关变化时取消未完成波形；触发确认后不在松手时取消确认脉冲。原动作同步调用的 tick／预览震动在长按回调中抑制，避免重叠。原有单击拍摄、录像调用的 longPress() 不整体替换。

反馈尊重 App 触感开关与系统触摸反馈开关。GPS 波形一致性和各触发时长的精确缩放通过针对性单元测试；实际震感需在带振动马达的手机上验收，模拟器无法验证手感。其余文档建议仍属待定，不代表本次全部实施。
