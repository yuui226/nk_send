# 横屏监看统一布局与 Dock

## 最终方案

1. 横屏直接采用原沉浸全屏的大画面，取消普通横屏／沉浸全屏两套布局及全屏切换入口。保留旋转入口，竖屏仍支持编辑工具，横屏不编辑。
2. 默认控制区提供 Dock、旋转、四个曝光参数拨轮、拍照／相机录像、DISP；端侧录制中额外保留停止入口。DISP 只读。
3. Dock 切换控制区内容：参数、普通拍摄、DISP 隐藏，同一块区域显示按用户排序、显隐和拍照／录像适用性筛选的小工具；Dock 和旋转始终保留。
4. 相机录像及端侧录制的停止入口始终可达；位置稳定，不因 Dock 切换或开始录制改变画面布局。
5. 依据实际空白自适应：右侧足够时两列；只够一列时单列；右侧不足而底部有足够原生留白时移到底部。底部工具两排，空间不足时只滚动工具区域。
6. 右侧和底部都不够时，使用可收起的覆盖控制面板，固定保留 Dock、拍摄／停止入口；面板展开不改变画面大小。允许有限覆盖，不把按钮压到无法操作。
7. 画面尺寸只依赖窗口、画幅／反挤压和原沉浸画面边界，不依赖 Dock、录像状态、工具数量。布局选型不依赖录制状态，避免录制开始时跳位。
8. 参数及小工具菜单继续复用原菜单。Dock 区作为普通布局，不增加弹窗层级；菜单靠近实际按钮，尽量靠右。不让隐藏／收起过程中的控件接受触摸。
9. Dock 呼出／收回复用全局 Genie 动画；切换时避免两组按钮同时可点击。拍摄、对焦、录制和参数读写复用原有回调，不修改协议、传输、编码或后端逻辑。

## 最终实现核对

- `RemoteScreen` 的横屏分支只保留一套取景器和控制区；`RemoteTool` 删除全屏项，竖屏固定入口保留旋转，竖屏编辑继续使用原布局。旋转锁定仍走原回调。
- `LandscapeMonitorLayout` 先计算原沉浸画幅，再安排控制区；Dock、工具数量、开始／停止录像不改变布局输入。录像模式为电平预留固定空间，电平开关不再令画面变化。
- `LandscapeMonitorControls` 右侧一／两列工具纵向滚动，底部两排工具横向滚动；底部参数在空间不足时改为两行两列，避免四个拨轮被挤窄。覆盖方案顶部保留 Dock、参数入口槽和旋转，下方保留拍摄及停止槽，不因面板显隐跳位。
- 工具列表直接取当前照片／视频布局的 `shownTools`，不复制排序配置；横屏没有编辑入口。端侧录制工具在 Dock 内使用紧凑按钮，开始／暂停仍用原回调，停止在独立固定位置。
- Dock 与参数区使用 `rememberGenieVisibility`／`GenieInlinePanel`；覆盖背景放在动画内容里一起收放。拍摄与 DISP 淡出时保留槽位；相机正在录像时，拍摄键继续显示为原停止状态。端侧停止与 Dock 状态无关。
- 动画未完成及退出中的面板在 Initial 触摸阶段拦截操作；拦截条件使用 `rememberUpdatedState`，避免快速切换后读到旧状态。菜单继续由原按钮实际坐标定位，不新增一层弹窗。切换面板、窗口尺寸／画幅变化时关闭旧菜单，防止菜单挂在已经移走的按钮位置；返回键先收起 Dock／覆盖参数区。
- 参数修改、拍摄、相机录制、端侧录制复用原函数；没有修改协议、相机实现、传输、编码文件。未引入新依赖、图像副本或逐帧任务。横屏提示恢复可见，避免操作失败提示和旋转锁定提示被旧沉浸条件屏蔽。

- 横屏 DISP 保留此前高度，右侧布局靠近取景边界排列；窄屏覆盖方案使用右侧固定槽位，方形屏底部备用布局保持 DISP 原高度。
- 横屏端侧录制从 Dock 移出，固定在 DISP 正上方，不受 Dock 收放影响。复用竖屏原有 RecControlBar，保留开始、停止、暂停、继续、计时、保存成功和展开收回动画，不修改录制实现。
- 预留控制条最大展开宽度，DISP 与待机录制按钮中心对齐；不改变画面尺寸。竖屏原工具显隐和排序不变。
- 不进行模拟器验证；本次仅检查代码及 Kotlin 编译。


## 五项功能复查中的布局修正

- 端侧录制固定槽位加入后，矮屏的旧纵向堆叠会压缩 Dock。控制区能容纳 96dp 录制栏、16dp 间隔及快门时，将快门与录制／DISP 列并排；较窄而足够高的控制区继续上下排列。保留 DISP 高度及取景尺寸。
- 底部备用布局按扣除固定控件后的实际宽度选择 4／2／1 列参数，保证单项至少 80dp；高度不足时参数区域可纵向滚动，不挤压画面。
- 横屏录制已独立于工具列表，模式切换时不再按隐藏工具配置停止它；转回竖屏后仍遵循该模式的显隐配置。
- 删除原来的固定两列判断与重复快门占位路径，复用现有录制控制条、按钮回调和 Dock 动画。
