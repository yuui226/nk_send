# Z传文档索引

`docs` 下的资料按用途分类存放。新增文档时请优先放入对应目录，避免再次散落在根目录。

## 目录分类

| 目录 | 内容 |
|---|---|
| [`产品与界面设计`](产品与界面设计/) | 页面原型、交互稿、视觉方案、照片效果与滤镜管理设计 |
| [`技术调研`](技术调研/) | Nikon PTP、连接方式、遥控能力和传输架构调研 |
| [`测试与验证`](测试与验证/) | 真机回归、遥控、预览和大文件验证清单 |
| [`商业化与授权`](商业化与授权/) | 激活码、支付、自动售码和高级版购买流程 |
| [`发布与运维`](发布与运维/) | App 更新、OSS、官网下载和 Google Play 上架资料 |
| [`品牌素材`](品牌素材/) | Z传图标、ORYS 水印及其矢量素材 |
| [`宣传向资料`](宣传向资料/) | 宣传歌曲、更新公告和其他对外传播文案 |
| [`软著`](软著/) | 软件著作权申请、源程序材料、说明书和提交文件 |

## 维护原则

- 不在 `docs` 根目录散放业务资料；根目录只保留本索引。
- 原型 HTML 与配套截图放在同一分类目录。
- 调整路径时同步更新仓库内的 Markdown 链接和源码注释引用。
- 密钥、管理员令牌、生产数据库和其他敏感文件不得放入文档目录或提交到 Git。
