# iOS 预览返回定位与提醒动画记录

## 行为依据

- 用户明确要求：当前照片完整位于照片列表可视区域时不滚动；完全离屏或任一边被裁切时才辅助滚动。
- 返回目标仍按安卓流程处理：预览中的连拍成员如果尚未展开，先在黑色预览层下展开，再取得成员格子的真实位置。
- 提醒动画对齐安卓 `FileListScreen.kt`：连续两次脉冲，每次 110ms 放大到 1.055、155ms 回到 1、间隔 35ms，并叠加最高 11% 的白色亮度层。

## 修复

- 顶部工具按钮隐藏时仍保留固定 36pt 的 `safeAreaInset` 槽位，防止返回时槽位重新出现触发 ScrollView 自动补偿内容偏移。
- 分别测量 ScrollView 和顶部槽位的全局边界，以两者交集得到照片的真实可视区域，不使用整块 `UIScreen.main.bounds` 代替。
- 可见判断由矩形相交改为完整包含；仅部分显示时按最近的顶部或底部边缘做短距离滚动，完全离屏时保留远距离预定位。
- 提醒任务支持取消；快速连续打开/返回时，旧脉冲不会继续修改新动画的状态。
