# iOS 按钮主题作用域复刻

## 安卓行为依据

- 主题入口为 `SkinPreset` / `GlassButton`。四种主题依次为毛玻璃、木纹、相机按键、钛合金；设置页展示顺序与枚举顺序解耦。
- 只有 `GlassButton` 家族读取 `buttonSurface`、高光和实体纹理。`GlassSurface` 面板、弹窗、提示条、信息框始终读取不变的 `glass*` token，换按钮主题时不能一起变色。
- 照片列表队列控件分为两类：空闲“队列入口”是 `GlassButton`，跟随主题；出现速度、数量、生成中、Done 或暂停数量后改为状态胶囊，不受主题影响。开始/暂停是 `QueueExecutionButton`，同样固定为状态材质，不受主题影响。
- 跟随主题的主要交互包括：连接页/照片页设置入口、连接操作、信号与电池胶囊、筛选按钮、日期分组与整组入队、回顶、监看入口、预览工具、队列页返回/重试/清理、设置页操作、照片效果收藏/导入、监看页工具以及本地照片工作台操作。
- 不跟随主题的交互包括：筛选 chip、拨轮、选项行、纯文字关闭/取消、相机快门主体、录制控件外层状态面板，以及业务状态胶囊。连接大卡片与模式徽标是安卓明确声明的局部家族化例外：实体主题只改变承载面/徽标，不把正文区域铺成按钮纹理。

## iOS 对齐

- `ZTransferGlassButtonStyle` 作为唯一主题按钮入口；补齐深浅色钛合金、胡桃/蜂蜜木纹、黑色相机键帽与毛玻璃材质，实体纹理使用裁切在最终形状内的确定性绘制，避免矩形贴图接缝。
- 木纹不再使用规则正弦线近似；逐项移植 Android `SkinTexture.kt` 的 256 px 周期纹理计算（非对称年轮、多尺度弯曲、顺纹纤维、细导管和柔和木结），沿用深色 0.30 / 浅色 0.21 的纹理强度及同一明暗叠色。纹理与安卓一样在后台生成，生成期间只显示稳定木质底面，避免切换主题阻塞主线程。
- 按压参数对齐安卓：相机键帽 0.982、钛合金 0.970、其余 0.965；实体按钮同时缩短投影并产生轻微下沉。相机键帽统一冷灰丝印，钛合金统一凹刻色；显式 `materialContentColor` 用于品牌 Z 标、灯泡和收藏等语义图案。
- 内容着色遵循 Android 绘制顺序：毛玻璃和木纹保留调用方原始文字/图标颜色；钛合金将整行压成默认凹槽色，相机键帽将整行压成冷灰丝印；只有显式 `materialContentColor` 才覆盖后两者。Z 标因此在木纹下保持主文字色，在钛合金/相机键帽下使用品牌黄。筛选、提示灯泡、队列入口及连接页的木纹专用前景均按安卓各自 palette 处理。
- 新增 active/activeColor/activeOutline、panel、disabledAlpha 与 followsSkin。筛选和收藏使用材质专属激活色；弹窗内 Clear 使用低投影 panel 变体。
- 修正作用范围：队列开始/暂停固定毛玻璃；空闲队列入口跟随主题，状态胶囊保持玻璃；照片预览、监看页、连接页小操作、本地照片工作台和设置页页脚改回主题按钮。
- 连接卡片在实体主题下使用安卓同源的哑光承载色和细边缘光；模式徽标复用对应实体材质。卡片正文、设置面板、筛选弹窗与提示条不读取按钮主题。

## iOS 专属液态玻璃

- 这是用户明确确认的平台差异：仅 iOS 26 及以上在按钮样式拨轮中增加“液态玻璃”，不修改 Android 的主题枚举和持久化。
- 材质直接使用系统 `glassEffect(Glass.regular.interactive(), in:)`，沿用现有按钮的精确尺寸、连续圆角、布局和业务状态；不叠加自绘噪点、实体投影或自定义按压缩放，交互形变交给系统原生液态玻璃处理。
- 筛选等 active 状态使用原生 Glass tint 表达，不额外画实体主题边框。实体 Android 主题下，队列状态胶囊仍保持既有材质；用户随后明确要求 Liquid Glass 覆盖整套队列按钮，因此仅当 iOS 26+ 选择“液态玻璃”时，队列入口、速度/数量/生成中/Done、开始/暂停统一使用原生交互玻璃，进度填充、状态颜色、显隐和宽度动画不变。
- 可用性有三层保护：设置页仅在 `#available(iOS 26.0, *)` 时加入选项；持久化值解析在旧系统回退到毛玻璃；RootView 和设置页出现时会把来自备份或同步的旧系统非法选择写回毛玻璃。因而 iOS 25 及更低版本不会显示空选项，也不会触发 iOS 26 API。
- 连接大卡片继续遵守“按钮主题不扩散到正文承载面”的作用域；选择液态玻璃时维持原有玻璃卡片，仅实际按钮使用系统液态玻璃。

- 2026-09-18：iOS 专属液态玻璃与队列数字命中时序合并完成 Debug 构建，并安装、启动于 iPhone 17 Pro 模拟器（进程 `com.ztransfer.ios`）。SDK 可用性检查覆盖设置入口、持久化解析与最终材质渲染；当前模拟器为支持版本，低于 iOS 26 的隐藏/回退路径由 availability 分支及单元断言覆盖，未在低版本 runtime 实机运行。
