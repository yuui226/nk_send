# Z传 iOS 原生复刻计划与任务清单

## 目标与边界

本计划对应 `ios` 分支。iOS 使用独立的 Swift/Xcode 工程，代码放在仓库根目录的 `ios/`，不引入 Kotlin、KMP 或 `shared`。安卓 `app/` 作为行为对照，不参与 iOS 编译；不为 iOS 复刻改动安卓结构，也不自动删除安卓参考代码。

安卓端已经迭代验证过的连接判断、协议顺序、状态流转、错误处理、取消、重试、持久化和文案含义，是 iOS 的功能基准。iOS 可以使用 SwiftUI、UIKit、Core Image、Metal 等原生实现来获得自然的页面和动画体验，但不能因为换了 UI 技术而改变业务结果。

## 强制复刻原则

本节与 [项目记忆](../项目记忆-iOS复刻规则.md) 同为后续开发、审查和验收的长期约束，由仓库 `AGENTS.md` 引用。每次开始或恢复任务时先阅读，子 agent 执行同一规则。

1. **安卓行为是事实来源。** 所有 UI、动画、点击/长按/拖动操作、判断条件、状态流转、协议时序、错误、取消、重试、持久化和文案含义，都必须先从安卓代码和测试中确认，再在 iOS 中实现。不得凭经验补功能或修改语义。
2. **不添加用户没有要求的内容。** 不增加多余文本、页面、按钮、入口、跳转、提示或源码/项目地址展示；安卓没有的能力，iOS 不自行创造。
3. **平台实现可以不同，结果必须一致。** SwiftUI、UIKit、Core Image、Metal 和 Swift Concurrency 可以按 iOS 习惯选用，但只能改变实现方式，不能改变用户可观察的结果。确实无法保持一致时，先讨论并在任务记录中写明差异。
4. **公共组件优先且保持可维护。** 字体、颜色、间距、按钮、拨轮、弹窗、状态模型、动画曲线和错误映射应集中封装；组件有清晰职责，避免复制粘贴、临时占位和无法测试的巨型文件。
5. **每项功能必须闭环。** 入口、正常路径、边界、错误、取消、重试、恢复、持久化、动画和测试全部完成后，才能在清单中标记完成。
6. **文本与可见行为逐项对照。** 所有文本逐字一致，包含标点、空格、大小写和版本号格式；页面元素位置、显隐条件、按钮功能、手势、动画触发/中断/恢复均须对照安卓。截图辅助核对，不能代替阅读实现。不把原生系统默认交互直接当作复刻完成。
7. **验证记录如实填写。** 编译成功或接口存在不代表功能完成；未执行的测试不写通过。发现过去的完成状态不准确时立即更正，保留问题和后续工作记录。
8. **动画参数与时序也是复刻内容。** 时长、延迟、曲线/弹簧参数、位移、缩放、透明度、交错顺序和手势联动逐项依据安卓实现；连续触发、中断、取消、恢复和退出清理一并核对。不能用系统默认效果替代，优化性能也不能擅改行为。
9. **复用不改变状态归属。** 复用组件、模型类型、渲染器和公共逻辑；安卓独立的配置、草稿、持久化作用域及任务生命周期继续独立。工作台与相机传输的照片效果配置分别保存，不能因使用相同控件而合并。不为 iOS 复用改动安卓结构。
10. **按场景完成闭环。** 每次只选定一个用户场景，沿入口、加载、交互、正常/异常/取消/重试/恢复、持久化、动画和验证完整对照安卓；照片列表与传输作为一条连续链路一起完成，未闭环前不交叉处理 GPS、监看或其他无关页面。

第一条实际连接链路选择 USB 有线连接。先把“插入相机—授权—建立 PTP 会话—读取文件—预览—下载”跑通，再扩展 Wi‑Fi STA、AP 和 BLE/GPS。USB 能力必须以真实 iPhone、转接设备和 Nikon 机身验证结果为准，不能只按模拟器结果判断。

## 待处理问题（2026-09-13 用户真机反馈）

以下问题由用户在当前工作台版本中直接操作发现，全部保持未完成状态；在逐项修复并完成真机回归前，不得把相关任务标记为完成，也不得以“已能编译”代替验收。

1. **滤镜预览未生效**：工作台选择滤镜后，预览图没有展示对应滤镜效果；需要沿安卓的滤镜目录、参数和预览渲染路径逐项核对，不能只显示选项名称。
2. **边框效果不是安卓实现**：当前 13 个边框样式为臆想实现，未按安卓端完整版式、颜色、间距、元数据布局和水印锚点复刻；必须以安卓 `PhotoFrameExporter.kt` 及相关预览代码为唯一依据重做。
3. **滤镜收藏误触拨轮**：点击滤镜收藏按钮会改变当前选项，并可能把错误的滤镜加入收藏；需要隔离按钮与拨轮的命中区域，并验证收藏前后当前滤镜和强度保持不变。
4. **边框收藏状态错误**：边框无法正确加入收藏，取消收藏也不能稳定生效；需要按安卓完整收藏对象（边框预设 + 水印配置）进行单次原子更新，并验证重新选择、取消、重启后的持久化。已修正一个确定差异：边框拨轮恢复安卓固定预设顺序，收藏只显示星标，不再把收藏项移到拨轮前面，避免同一 detent 选择出不同边框。
5. **水印控制全部失效**：水印无法开启或关闭，水印设置入口及展开后的各项按钮点击后没有效果；需要核对开关、展开状态、内容类型、文本/图片和各拨轮的绑定及状态写回。
6. **批量生成速度过慢**：工作台生成效果图的速度明显低于安卓；需要对照安卓批处理管线检查图片解码、滤镜/边框/水印渲染、并发限制、缓存和写入流程，不能只通过降低质量掩盖性能问题。
