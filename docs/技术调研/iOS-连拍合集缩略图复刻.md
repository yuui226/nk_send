# iOS 连拍合集缩略图复刻

## Android 行为依据

- 折叠合集的三张成员使用独立 `BurstStackPhoto`：只绘制缩略图、加载占位和主题边框。
- 普通照片格的文件格式、连拍成员、保护、传输状态和已传输角标不进入叠放成员层；合集自身只在顶层显示连拍标志、成员数量、整组入队和展开按钮。
- 合集展开后，成员恢复为普通 `ThumbnailCell`，其自身角标按原规则显示。

## iOS 修正

- `CameraThumbnailView` 增加显式 `showsCornerBadges` 开关，默认保持普通照片格行为。
- `BurstThumbnailView` 的三张叠放成员统一传入 `showsCornerBadges: false`，仅隐藏角标与传输遮罩，不改变缩略图读取、缓存、占位、旋转和叠放布局。
- 合集顶层的连拍标志、数量、入队按钮和展开按钮保持不变；展开后的成员仍使用默认角标模式。
