# iOS 照片预览长按与布局复刻

## 行为依据

- 照片列表手势以安卓 `FileListScreen.kt` 的 `combinedClickable` 为基准：“点击预览”开启时，点击预览、长按入队；关闭时，点击入队、长按预览。两种手势只交换入口，不复制传输校验或预览状态流转。
- SwiftUI 默认长按阈值为 500ms，本次根据用户对响应速度的明确要求进一步缩短为 250ms，同时保留 12pt 移动容差，避免滚动照片列表时误触发。
- 预览布局以安卓 `PhotoPreview.kt` 为基准：图片分页舞台覆盖完整屏幕，文字与按钮叠加层单独遵守安全区；右侧控件距右 20pt、距底 80pt，44pt 圆形按钮间隔 12pt。
- 预览左上角按安卓当前实现只显示文件名，不额外显示当前序号/总数；传输状态和已传输标记仍紧跟文件名。
- 直方图按钮、旋转、加号和连拍收起/展开符号按安卓 Material 24x24 路径或绘制参数复制，不使用外形不同的 SF Symbols。旋转使用安卓同款 220ms FastOutSlowIn 时序。
- 直方图按安卓 `HistogramOverlay` 的实现复制为 118x62pt 圆角容器和 256 档辉度曲线；高清照片加载期间显示顶部 2pt 进度线。
- 旋转按安卓 `ZoomablePreviewViewport` 复制：按钮每次累加 -90°，用 220ms
  FastOutSlowIn 对角度连续插值，每帧根据当前角度重算旋转包围框和适配缩放，不在
  90° 终点更换图片或跳变尺寸。
- 预览手势层遵守安卓的“1× 不消费单指拖动”规则：缩放手势与分页手势并行，
  图片平移只在放大后启用，1× 横向拖动由 `PageTabViewStyle` 接管左右翻页。
- 上滑入队使用安卓同款方向锁：越过 8pt 触摸阈值后，横向/向下手势交给分页；
  上滑量达到横向量的 1.15 倍后锁定入队手势，在当次触摸结束前禁用左右分页，
  使用 96pt 触发线和越线 0.22 阻尼。
- 直方图开关状态与具体照片 ID 的计算结果分离保存：滑入连拍合集页时只用
  180ms 渐隐当前曲线，不关闭用户开关、不清空来源照片的直方图；返回普通照片
  后按照片 ID 立即恢复或从已显示位图重算，再渐显。
- 连拍合集的入队和展开按钮属于合集分页内容，与三张叠放缩略图共用分页位移，
  滑入和滑出时不再固定在屏幕上。
- 普通照片右侧的收起、直方图、旋转和入队按钮作为同一组页面状态层：
  切换到连拍合集时整组用 180ms 渐隐，回到普通照片时整组渐显，退场期间立即禁用点击。
- 图片放大后的单指平移使用 8pt 触摸阈值，不再用 0pt 拖动识别器抢占所有轻点；
  因此放大状态下可稳定识别双击并用 240ms 过渡恢复 1×，真实拖动越过阈值后仍由图片平移接管。
- 单击和双击改为同一组互斥空间点击识别：单击只在 1× 关闭，双击以实际触点为锚点
  放大到 2.5×，再次双击用 240ms 回到 1×；回落动画结束前仍锁住分页和上滑入队，
  不在图片尚未归位时提前释放手势所有权。
- 缩放上限与安卓一致，为 `max(4×, 原图 1:1 像素倍率)`；缩放和平移过程中持续按
  当前旋转方向约束偏移，照片不能被拖出视野露出无效空白。双指缩放开始后立即否决
  当次上滑入队，避免第二根手指加入时把缩放误判为入队。
- 上滑入队只在预览展开进度达到 99% 后参与方向判定；打开/关闭、放大、双指缩放、
  连拍切换和入队飞行动画期间均不接管触摸。

## 实现位置

- `ios/ZTransfer/UI/PhotoListView.swift`：长按时长、手势入口与共用入队逻辑。
- `ios/ZTransfer/UI/PhotoPreviewView.swift`：全屏分页舞台、右侧控件、Material 图标、256 档直方图和旋转动画。
- `ios/ZTransferTests/DomainModelTests.swift`：250ms 手势阈值与 256 档黑/白端点的最小回归测试。
