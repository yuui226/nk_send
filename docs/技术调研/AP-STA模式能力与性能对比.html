相机端配置持久化相机热点配置为 AP 路径；手机侧可记住 Wi‑Fi。首次完成“连接至计算机”配对，相机保存配置文件，下次可直接选择该配置。已实现 STA 的核心价值。
连接发现按相机网关与固定地址连接。上次 IP 仅在当前子网内才尝试，再通过 mDNS 与局域网/热点候选发现 PTP/IP 服务；只有完整相册能力验证成功才发布“已连接”，仅监看会话不会再伪装成空相册。实现不同 避免旧热点地址触发数秒无效握手；复杂 LAN 的发现时间仍可能高于 AP。
断线与重连网络回调 + 心跳自动重连。心跳、上次 IP、STA 发现与退避重连。行为对齐 实现因拓扑不同而独立。
列表 UI / 日期分组共用 FileListScreen。共用 FileListScreen。完全共用
类型筛选由 ObjectInfo 提供真实扩展名。Z30 已验证 JPG / NEF / MP4；已知 handle 类型直接识别，未知类型回退读文件头。当前机型可用 新 handle 类型需实机补充。
拍摄日期ObjectInfo 直接返回。GetObjectsMetaData(0x9434) 一次返回整卡日期；未知布局回退文件头。已优化 Z30：829 项仅 13,272 B。
文件大小ObjectInfo 32 位字段；超大文件用 GetObjectSize。每项使用 8 字节 GetObjectSize 结果。数值可靠 STA 多一条小命令/文件。
文件原名ObjectInfo 返回相机精确原名。Z30 拒绝文件名属性；通过 MakerNote 锚点和 handle 序列恢复 DSC_####。默认前缀可用 相机自定义三字符前缀目前无法保证精确恢复。
保护状态ObjectInfo 的 ProtectionStatus，列表筛选和锁标识可用。配对 Z30 拒绝 ObjectInfo，当前没有可靠来源。当前不支持 STA 中默认按未保护处理。
双卡 / 卡槽筛选ObjectInfo 提供每个文件的 StorageID，可归属卡槽并合并去重。可枚举 StorageID，但直接读取模式尚不能可靠得到每个对象的精确卡槽归属。未完整支持 Z30 单卡不受影响；双卡 STA 需实机研究。
新到旧顺序每卡反转原始 handle 顺序；双卡按真实日期流式归并。同样使用新到旧 handle 顺序和共用发布模型；批量日期索引提供真实日期。单卡已对齐 双卡归属仍受上一项限制。
渐进首屏12 项 ObjectInfo 一批，批间补缩略图。语义相同；STA 内部用 1 → 3 → 12 的发布粒度抵消私有命令延迟，并复用连接验证阶段已经取得的单卡 handles。体验对齐 首次目录不再紧接着重复 GetObjectHandles。
内存 / 磁盘缩略图缓存内存 LRU + 按相机隔离的磁盘缓存。同一套缓存；直接模式主键使用 handle + size，并兼容文件身份备用键。已生效 暖缓存不再逐项读 128 KiB 文件头。
JPG 缩略图相机 GetThumb。磁盘命中零网络；未命中时从 128 KiB EXIF 头提取。可用 冷缓存比 AP 多传文件头。
NEF 缩略图相机 GetThumb，通常成本较小。从 NEF IFD 或 JPEG 扫描定位内嵌预览；只对可见项按需加载，首张以 256 KiB 可靠探测，后续复用已校验的同会话偏移并在失败时自动回退；最近编码缩略图采用 4 MiB LRU，取消重建格子不会重复下载。可用但仍慢于 AP 不做整卡后台 RAW 探测，避免拖垮列表。
视频缩略图相机 GetThumb。先读 128 KiB 内嵌封面；缺失才扩大到有界 8 MiB 并尝试抽帧。可用但实现不同
大图交互顺序已有缩略图立即显示 → 当前页 FHD → EXIF → 相邻页预取。完全复用同一 PhotoPreview 顺序、动画、旋转、缩放和内存窗口。完全共用
JPG FHD 预览GetFhdPicture(0x920F) 返回相机生成预览。新机型先尝试相机 FHD；Z30 配对档案拒绝后，读取 MPF 精确 FHD 项（实测 1620×1080）。已实现 不是原图模拟，不下载主 JPEG。
NEF 大图由相机 FHD 能力决定。从小到大验证已索引内嵌 JPEG，优先选择首个达到 FHD 长边的候选；未知索引时进行有界前缀探测。可用 避免为了预览默认传输最大的内嵌 JPEG；不保证每个 NEF 都含可解析预览。
视频大图 / 播放当前预览页不会对视频请求 FHD，也没有在线播放。相同。两种模式均不支持在线播放
EXIF 展示读取 128 KiB 文件头并走共用解析。同一解析；STA 最多保留 4 项、每项 512 KiB 的最近前缀，供 MPF、RAW 索引和 EXIF 复用。已对齐并适配
连拍合集 / 筛选 / 展开前端从文件名和日期派生。共用同一算法和 UI。完全共用 依赖恢复后的文件编号与日期准确。
手动选择传输单张、整组、预览上滑、批量选择。共用相同入口与队列。完全共用
已传判定文件名 + 大小，并兼容副本后缀。共用同一判定。逻辑共用 自定义文件名前缀场景受原名恢复限制。
下载 / 断点续传 / 取消共用队列、SAF 临时文件、完整性校验和分块让路。共用全部上层逻辑；协议层强制使用已验证可用的 PartialObjectEx。已验证可传输
传输与前台交互优先级分块之间让 FHD / EXIF / 可见缩略图插入；监看与扫描互斥。共用同一 CameraIoGate 与暂停/恢复快照。完全共用
新拍媒体自动入队ObjectAdded + 连接级 handle 差量。代码路径共用；单个新增对象会回退读取自己的头部元数据。待持续实机验证 依赖配对 STA 事件投递可靠性。
遥控 / 监看与图传并存退出监看后按 handle 差量补列表，扫描期间前台交互优先。配对 Z30 已可监看和浏览/传输；同样通过暂停扫描、退出后续扫实现共存。当前目标已打通

本次日志的性能结论

整卡日期索引13,272 B一次映射 829 项，已成功。
旧方案日期文件头流量约 103.6 MiB829 × 128 KiB，现已从暖缓存路径移除。
RAW 可见缩略图首张 256 KiB，后续约 192 KiB 起同会话偏移命中时减少约 25% 前缀流量，失配自动回退。
JPEG MPF FHD约 0.96 MiB / 2.25 s实测 1620×1080；耗时主要取决于当前 STA 链路吞吐。
NEF 内嵌 FHD约 0.86 MiB / 2.35 s尺寸校验后选择 1620×1080 候选，未读取同文件约 2.03 MiB 的更大预览。
被拒绝的 FHD 探测约 0.34 s / 会话0x920F + 0x90C4 首次拒绝后会话内熔断，不会逐张重复。
日志中的第二组 filename / JPEG / GetObjectsMetaData 行是扫描暂停后恢复时重新输出了会话诊断， 并不代表这些命令全部再次执行；现已改为每个相机会话只输出一次元数据诊断。handles=717 表示打开大图前已经处理 112 / 829 项，关闭后从快照剩余位置继续，不是从头重扫。
