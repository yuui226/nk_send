# iOS 连接成功动画性能优化记录

## 行为基线

- 连接成功动画继续使用同一个 `celebrationStart: Date` 作为绝对时间源，不累计帧进度，掉帧后按实际时间追帧，避免多个图层相位漂移。
- 已确认的 iOS 动画参数保持不变：主段 620ms、成功光效 760ms、smootherstep 主曲线、10pt 飞行弧线、`1 + progress * 1.12` 徽标缩放，以及屏幕水平中心和屏幕高度三分之一处的飞行终点。
- 被选中的卡片徽标仍是唯一实例：静止时覆盖在卡片标题槽位，成功后由原实例起飞；不得恢复为复制一个徽标参与动画。
- 成功触感仍在主段 620ms 边界触发，页面切换与连接业务状态顺序不变。

## 性能处理

- 删除连接页最外层的逐帧 `TimelineView`，避免每个显示帧重算整页、两个卡片的所有文字与控件、GPS、设置入口和弹窗树。
- 卡片表面、唯一徽标/成功光效、外围透明度各自设置小范围刷新边界。所有边界每帧都从同一个绝对开始时间计算进度，因此拆分刷新区域不会改变动画时序。
- 支持的 ProMotion 设备请求最高 120Hz 更新；不支持的设备由系统按屏幕能力合并刷新，不改变时间或路径计算。
