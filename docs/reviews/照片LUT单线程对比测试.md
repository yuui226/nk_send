# 照片 LUT 原生方案定稿

采用 Native16K：单线程、每批 16384 像素，保留 Kotlin 兼容回退。已删除 Debug 执行方式选择、Native64K 和重复生成绕过查重的实验逻辑。监看 GPU 路径不变。

用户实测约 2067 万像素、33³ LUT：Kotlin 颜色计算 4573–6463ms，Native16K 418ms，Native64K 394–409ms。不同照片不能证明 64K 稳定优于 16K，因此采用较小缓冲和较细取消粒度的 16K。用户已确认生成图像正常。

生成总耗时仍包含排队、解码、边框渲染、编码和保存；偶发 8.8 秒必须结合该张分段日志判断，不能直接归因于 LUT。暂不增加并行计算线程，避免与传输竞争 CPU。即使将典型 418ms 颜色阶段理想减半，整张也仅节约约 209ms。

保留 tools/test-photo-lut-host.sh 验证原生和 Kotlin 逐像素一致性、取消及批次边界；不打包、不安装、不运行真机。
