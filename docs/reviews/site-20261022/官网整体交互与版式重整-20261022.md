# 官网整体交互与版式重整

本次依据用户要求重新整理整页图文、功能说明和动效。前一版原生 details 的展开会改变列宽与总高度，进而使相邻截图与后续章节移动；本版不再使用这套折叠结构。

## 最终内容与结构

- 阅读顺序：首屏 → 选片与传输 → 照片效果 → 监看与遥控 → 连接方式 → 版本权益 → 常见问题 → 下载。
- 照片列表始终作为第二章节；筛选窗在列表旁，20 项使用设置移到同一章节。
- 监看区只保留 27 项监看工具。两处功能浏览器以分类、固定位置的图标按钮、独立说明区呈现；每组记住已选功能。
- 所有分组与说明参与同格布局的自然尺寸计算。切换只改变可见性与可访问状态，不改变高度；长文不会被固定高度裁切。
- 监看截图增加石墨色手机外框；保留原图全宽与两侧 App 留白。内屏裁切为原图 x=0、y=112、宽1080、高2208，完整保留顶栏与快门，排除系统状态栏和导航条。
- 橘猫照片严格限制在原图取景框 x=36、y=294、宽1007、高669。取景模式、曝光尺与帧率叠层保留对应视觉信息；原截图文件未修改。
- 照片效果保留生成的海边预览和滤镜、LUT、胶片颗粒、边框、水印五组控件。新增准确亮点“也能批量处理手机里的照片”，替换空泛描述。
- 传输队列缩为紧凑补充，集中说明原文件传输、实时入队与大视频续传；删除“分块”等实现措辞及低价值重复。
- 连接方式与 FAQ 改成稳定面板；移除循环浮动、双重位移和展开跨列动画，仅保留短暂淡入与颜色反馈。
- 统一留白、字级、按钮、圆角、配色与手机适配；清理前几轮遗留的无用演示样式。
- 保留 Android 下载、iOS 敬请期待、FAQ 的已确认产品事实和原有隐私/条款页面。
