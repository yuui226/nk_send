竖屏工具行 — 测量换行
HD / FPS / 直方图 / 参考线 / 斑马纹 / 水平仪 按顺序从左贪心填满第一行， 放不下的自动折到第二行左对齐；全屏与旋转永久钉在第一行最右，永不换行， 中间用弹性空隙隔开。第二行没有溢出时完全不渲染（没有空行、没有幽灵高度）。 两行都与取景器同宽、共用左边缘。按钮高 36px、宽 = 图标 + 24px、间距 6px、右侧预留 97px。

沉浸式全屏 — 无黑边
始终横向（90° / 270°）。画面取 insets 之后能容纳的最大不失真矩形， 容器比例 == 画面比例，因此没有上下黑带；内容左上对齐。 全屏里没有底部工具行（工具与录制控制全部隐藏），省下来的宽高全给画面。 状态栏 inset 在 90° 落左、270° 落右，同侧还带屏幕挖孔，故该侧取 max(状态栏, 挖孔, 6px)；导航栏 inset 在对侧。 取景器保留 14px 圆角与 #0D0D0D 背板，四周同色 → 无接缝。 右上角只有两枚 40×40 玻璃按钮（22px 圆角、无描边无高光）：退出为实心箭头 18px、 旋转为线性图标 20px —— 差 2px 让两者视觉重量相当。 进入 200ms 淡入(40ms 延迟) + 240ms 0.96→1.0；退出 140ms 淡出 + 160ms 1.0→1.02； 方向切换为交叉淡变（不做 90°→270° 连续旋转，避免经过倒置）。
