## 已实现

- [x] 新增 3×3 网格＋双对角线、4×4 网格＋双对角线。循环顺序为关闭、九宫格、九宫格＋对角线、四等分网格、四等分网格＋对角线、中心、黄金分割。保留无画面预览以及反挤压适配。2.25:1 参考框暂不实现。
- [x] 缩放窗口固定为原本拟合后的画面矩形；放大内容不能填满窗口外的黑边。拖动边界及导航框使用同一画面矩形，保持长宽比。
- [x] 实时传输改为关闭、全部、JPG、RAW、视频五档，沿用设置中的拨轮及触感开关。
- [x] JPG 接收 .jpg/.jpeg，RAW 接收照片 .nef，视频接收 .mov/.mp4，全部为这三组。忽略扩展名大小写。此次不增加其他文件格式的浏览或传输能力。
- [x] 独立持久化档位；旧开关开启迁移为全部、关闭迁移为关闭。
- [x] 类型筛选仅决定后续自动入队，不改变列表筛选、手动入队和已有队列。不符合类型的新文件不会因之后切换档位自动补入。
