# 边框宽度自定义

## 交互与范围

- 设置窗照片效果、本地照片效果工作台共用同一编辑器。
- “边框信息”改为“边框设置”（英文 Frame settings，繁体 邊框設定）。
- 展开后顶部显示宽度拨轮，100%～200%，步长 10%，默认 100%。
- 关闭边框时收起设置；沉浸没有外边框，不显示宽度。
- 每个样式独立记忆；两处沿用原有独立配置。边框收藏包含宽度，收藏状态下调整宽度同步更新收藏。

## 渲染规则

- 只扩展外围留白；原尺寸导出保持照片矩形的像素宽高，照片不被缩小或裁切。
- 常规、品牌、签名、档案、胶片边缘按原有各边留白扩展。
- 铭牌只增加底部信息带高度。
- 方形画廊各方向等量增加，保持方形。
- 参数海报增加等量外围空间，避免把竖图左边的参数列加倍拉宽。
- 胶片画廊只增加外部留白，胶片条和齿孔保持原有尺度。
- 文字、Logo、文字水印、描边与圆角以基础设计尺寸为单位，不因画布扩大整体放大；排版位置随可用区域调整。
- 100% 不执行扩展，沿用基础布局。另修正原有 COLOR_ARCHIVE 分区导出误走通用布局的问题，使其与预览一致；仅该模板增加独立输出版本标记。

## 流程与性能

- 宽度存于既有逐模板展示配置（PhotoFrameMetadataSettings），共用序列化、输出指纹、预览缓存身份与任务快照，避免增加另一套状态源。
- 已入队任务、重试、已有原图生成、裁切后生成均使用任务快照；之后调整设置不会改变已入队任务。
- 总开关仍只控制是否生成，不清空设置。
- 宽度不引入相机请求。预览复用当前滤镜/LUT 中间图，仅边框输出缓存失效。
- 扩展后再次限制预览长边；导出沿用分区解码及分配前内存检查，不复制一张完整的旧边框大图。
- 大边框会增加输出画布内存与编码工作量，不能视为零成本；上限限制在 200%，不静默降低照片分辨率。

## 检查

- 布局测试覆盖所有模板、100～200% 全档、横/竖/方/超宽/超长/小图：原图像素尺寸、留白不缩减、方形保持、沉浸不变、预览长边限制。
- 配置测试覆盖逐模板序列化、宽度输出指纹、边框收藏及工作台配置归一化。
- 本次不进行真机或模拟器操作；实际视觉与操作体验由用户验收。

## 逐模板布局复查

以下是绘制代码与几何约束检查，不代表已完成设备截图视觉验收。

| 模板 | 加宽后的内容定位 |
| --- | --- |
| 雾白 | 照片外扩，标题、镜头与参数在底部信息区居中，字号依赖基础尺寸 |
| 暗夜 | 同共用信息区，背景铺满新画布，文字仍使用浅色配色 |
| 简白 | 白底外扩，信息居中，照片描边保持原粗细 |
| 毛玻璃 | 面板随底部空间扩展，文字居中；修正阴影大小及偏移随画布放大的问题 |
| 铭牌 | 仅加高底部，左右信息栏和分隔线仍以照片宽度定位，文字块居中 |
| 沉浸 | 不扩展、不显示宽度，图内信息及水印不受影响 |
| 品牌内嵌 | 外框扩展，品牌、参数和水印仍相对照片定位，保留避让逻辑 |
| 品牌留白 | 图内参数保持位置，底部品牌与署名居中；限制行距随留白增长 |
| 经典签名 | 顶部标题在上留白居中，底部信息在下留白居中；限制信息行距增长 |
| 艺术装裱 | 保持方形，内层装裱随照片定位；底部文字居中，限制行距增长 |
| 色彩档案 | 文字和色块仍位于照片宽度内，整体在底部留白居中；限制行距增长 |
| 胶片画廊 | 孔位、胶片条和装饰字跟随照片，保持原尺度；底部信息限制行距增长 |
| 胶片边框 | 侧面装饰字在对应侧边内定位，底部信息居中；限制行距增长 |
| 参数海报 | 竖图左参数列跟随外围位移，不拉宽；横图底部两列继续按照片宽度定位 |

本轮为扩展后的底部留白单独记录增量，文字间距使用扣除新增留白后的基准，新增空间用于整体居中而不是拉散行距。100% 增量为零。预览缩放同步缩放增量，不增加位图或相机请求。新增“扣除增量后底部基准不变”的断言，边框宽度及导出共 54 项测试通过。
