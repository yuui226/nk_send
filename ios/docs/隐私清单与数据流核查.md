## 已确认的联网路径

1. PTP/IP：局域网中的相机发现与连接、图片和控制数据。核查入口 `PTPIPDiscoveryService`、`PTPIPSocketConnection`、`PTPIPPOSIXChannel`。
2. GPS 地名：`GPSCoordinator` 调用 Apple `CLGeocoder`。
3. 照片边框地名：`PhotoFramePlaceResolver` 将照片坐标交给 Apple `CLGeocoder`；城市或地区开关关闭时不由该路径发起查询。该路径与实时 GPS 开关分开。
4. 内购：StoreKit 获取商品和经验证的交易。不能由“没有自建支付接口”推导 Apple 不处理购买数据。
5. 系统文件提供方和照片同步：取决于用户所选目录、云盘及系统设置，不能承诺所有导出文件永不离开设备。

## 日志与缓存

- USB 时间戳诊断在 `#if DEBUG` 内且需环境变量显式启用；它不是正式版默认遥测。
- 照片地名缓存最多 32 条，仅内存；成功结果 24 小时，失败结果 60 秒。这不是运营者或 Apple 的服务端留存政策。
- 当前 `PhotoLUTStore` 将私有快照放在 Application Support 的 `photo-lut-snapshots`；Caches 下同名目录是旧版迁移来源，不能沿用“全部 LUT 在可清除缓存里”的旧结论。启动及选择变更触发清理，保留相机/工作台已选配置与运行任务/草稿持有的快照。
- 导入水印写入 Application Support 的 `ZTransfer/Watermarks`，按内容摘要定位；关闭水印开关不删除素材，未提供覆盖所有私有文件的一键清理。

## 发布产物和源码增量核查

2026-10-20 对上一轮 Release 模拟器产物执行动态库清点：`otool -L` 的两个架构只链接 Apple 系统框架及系统运行库，没有非系统动态库。工程列出的第三方编译源码为 libjpeg 系列及桥接代码；不把仓库中未参与构建的工具源码算作 App 实际依赖。

已读取 StoreKit 状态管理器：真实交易权益由 StoreKit 读取并保存在进程内的 grant/状态模型中；该文件的 UserDefaults/JSON 编码购买保存只用于 `#if DEBUG` 的模拟权益。Release 二进制中没有模拟权益存储键与三种已检查的 UI 测试启动参数。此结果不覆盖每一种调试入口，最终归档仍需再核对。

`Contacts` 框架用于格式化地理编码结果中的邮政地址（`CNPostalAddressFormatter`）；未见 `CNContactStore` 读取通讯录。不能仅凭链接 Contacts 就填写“收集联系人”。

`PTPTransferDiagnostics.persist` 的文件写入位于 `#if DEBUG` 内，启用时写本地缓存的 JSONL，约 2 MiB 轮换一次并保留上一份；正式版不能据此声称上传诊断日志。USB 日志也受 Debug 与显式开关约束。

缩略图会在相机缓存会话启动时申请一次异步清理：以最近连接标记或目录修改时间计算 90 天闲置窗口。它不是“每张照片保存 90 天”，也不保证恰好第 90 天执行；App 未运行就不会执行该清理。空文件、临时文件以及旧扁平 JPEG 缓存另有清理逻辑。

联网检索曾发现系统设置跳转，不是数据上传：`CameraWirelessSettings` 使用未公开的 `App-Prefs` 路径。用户确认后已删除该 helper 与所有无线设置入口，生产源码检索无残留；6 项连接展示与顶栏专项通过，详见执行记录。GPS 权限入口继续使用公开 `UIApplication.openSettingsURLString`。

## 出口合规技术事实

当前不能回答“完全没有加密”：

- `GPSProtocol.swift` 的 Nikon 配对挑战响应调用系统 CommonCrypto 的 Blowfish，另有应用实现的分组、异或和盐顺序，用于兼容相机配对协议。
- 多个效果、缓存及 Picture Control 文件调用系统 CryptoKit SHA256，用于内容摘要和缓存身份。
- 不能把局域网照片传输描述为已经端到端加密；配对转换并不自动提供照片数据加密。

Apple 对仅使用操作系统加密的情形通常不要求在 App Store Connect 上传加密文档，但非标准或专有协议仍需按实际情况判断。本项目尚需复核整个已链接代码及 Nikon 配对协议的分类，不能只因原语来自 CommonCrypto 就跳过协议层判断。此次未设置 `ITSAppUsesNonExemptEncryption`，也未代填任何法定声明。

后台准备时应带着上述技术事实回答问卷；若不需要文档，再把确定的豁免结论写入工程，避免以后每次上传重复填写。若后台要求材料，按实际分类准备，不能随意填写审批代码。

依据：[加密文档类别](https://developer.apple.com/help/app-store-connect/reference/app-information/export-compliance-documentation-for-encryption/)、[出口合规判定范围](https://developer.apple.com/help/app-store-connect/manage-app-information/overview-of-export-compliance)、[Info.plist 声明含义](https://developer.apple.com/documentation/BundleResources/Information-Property-List/ITSAppUsesNonExemptEncryption)。
