## 隐私政策起草前要核对的事实

助手检查代码和依赖后填写，不能先写成“绝不上传任何数据”再倒推实现。

- 照片及 EXIF：来源、处理位置、相机到手机路径、保存位置和用户清理方式。
- GPS：前后台启停条件、向相机传输的内容、是否另发服务器。
- 局域网和蓝牙：发现、连接、设备信息用途，是否有后台数据上传。
- StoreKit：App 接收的交易信息、是否有自有服务器验证或记录。
- 日志和诊断：是否保存或发送照片路径、设备标识、位置、网络地址。
- 第三方依赖与服务：真实数据接收方、用途、留存和删除机制。
- 对外联系方式、政策生效日期、适用地区及儿童相关实际定位。

权限说明、App 内行为、隐私政策与 App Store 隐私问卷应一致。隐私清单 `PrivacyInfo.xcprivacy` 另按 API 使用填写，不是政策网页的替代品。
