## 中文核对版

Z传是一款独立开发的相机照片传输与拍摄辅助 App。它连接兼容相机，提供照片浏览和传输、实时监看、支持的拍摄控制，以及手机本地照片效果处理。支持能力取决于相机型号、固件和连接模式。

相机相关功能需要实体硬件。随附视频拍摄了实际 iPhone/iPad 与相机的连接及交互，不仅是屏幕录制。测试硬件、线材和相机设置见上述提交信息。

### 无相机功能

无需连接相机。在首页点击“滤镜·LUT·边框·水印”，点击“选择图片”，使用系统照片选择器选择图片并返回。配置滤镜、边框等效果后，点击“生成”，按系统提示允许添加照片。结果作为新照片保存到系统照片图库。

### USB 相机测试

1. 打开相机，插入含测试照片的存储卡，按上述机型说明选择相应 USB 模式。
2. 使用注明的线材连接相机和 iPhone/iPad，保持相机开启。
3. 打开 Z传，选择 USB 连接入口，允许系统所需的相机访问权限。
4. 等待相机就绪并进入照片列表；选择测试照片，按提示选择保存目录并发起传输。
5. 检查传输结果；在该相机支持的模式下进入实时监看，改变相机取景内容验证画面更新。

【待核实：提交构建的按钮名称及操作顺序；根据实际机型补入必要步骤，不仅凭通用步骤送审。】

### 高级版与内购

免费版每日提供 25 次成功原片传输，单文件最大 400 MiB，以及 180 秒实际监看时长。年度和永久高级版解除这些软件额度限制，并解锁高级水印配置等列明权益。

购买入口：设置 → 解锁高级版（英文：Settings → Unlock Pro）。高级版界面的恢复按钮为“恢复购买”（Restore purchases），订阅管理按钮为“管理订阅”（Manage subscription）。

已购状态下，点击 Pro 徽章仅播放庆祝动画，不打开购买页。年度用户可通过设置中的“管理订阅”打开高级版界面，再点击其中的“管理订阅”进入 Apple 的管理界面；永久用户仍有有效/待确认年度续订时也保留管理入口。只有永久权益且没有年度订阅需要管理时，不应要求审核人员寻找不存在的订阅按钮。

### 权限与后台定位

- 相机访问用于 USB 相机浏览、传输及控制。
- 局域网用于无线相机发现与连接。
- 照片相关权限用于用户选择图片和保存生成结果。
- 蓝牙用于兼容的相机 GPS 连接。
- 定位用于向兼容相机提供拍摄位置。后台定位用于用户开启 GPS 后持续更新拍摄位置，并不是为了保持普通照片传输或监看运行。App 内关闭 GPS 会停止位置更新；系统也可撤回权限。
- 地点名称显示调用 Apple 地理编码服务，可能需要网络。

【待核实：GPS 开关的实际路径、后台定位演示步骤与最终发布包行为；在视频中提供对应时间点。】

### 功能边界

iOS 版本不提供手机端监看画面录像。相机自身录像控制属于不同功能，是否可用取决于相机和模式。

App 采用 Apple 购买账户进行交易，不使用 Android 激活码。当前未发现必须注册自有服务账号的路径；【待核实：最终构建确认无登录门槛后，在后台选择不需要登录，不提供虚构账号】。

It is not used to keep ordinary file transfers or live view running. Turning GPS off in the app stops location updates.
