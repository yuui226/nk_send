# 审核硬件演示拍摄脚本

2026-10-20，待实拍。此文件是拍摄准备材料，不是视频已完成的证明。

Apple 要求依赖外部硬件的 App 提供视频，展示 App 在实体 Apple 设备上配对并与硬件交互，不能只交手机录屏。[官方说明](https://developer.apple.com/help/app-review/before-submitting-for-review/complete-review/)

以下 3–5 分钟是本项目建议时长，不是 Apple 的硬性限制。无需口头解说；用另一部手机拍摄，配简短英文字幕即可。重点是证明连接与交互，不需要遍历全部工具、相机型号和固件。提交前根据最终版本调整入口名称与顺序。

## 你要提前准备

1. 最终候选 App、已充电的 iPhone 15 Plus、一台实际支持的相机和可靠数据线。视频应对应送审功能，不能把 Debug 模拟相机或模拟 Pro 当作真实功能。
2. 用另一台设备拍摄；固定机位，画面能同时看见手机屏幕和相机。避免反光，点击时短暂停留让文字可读。
3. 相机卡中准备几张你有权使用的样片；示例可拍静物，避免客户照片、住址、面孔或证件。清除手机通知，避免验证码入镜。
4. 记下下面六项。型号和固件可拍设备设置页作证，不需要拍序列号。

| 信息 | 本次值 |
|---|---|
| App 版本 / 构建号 | 【你补：最终拍摄版本】 |
| Apple 设备 | iPhone 15 Plus；若实际换机，按实填写 |
| iOS 版本 | 【你补】 |
| 相机型号 | 【你补：一个代表型号即可】 |
| 相机固件 | 【你补】 |
| 连接方式 / 线材 | 【你补：USB 或 AP/STA，线材及必要转接器】 |

## 主视频：一条真实连接流程

时间只是参考，以实际操作完成为准。不要剪掉失败后重连的关键步骤后假装一次成功；可以重拍一条正常流程。

| 顺序 / 建议时间 | 你实际操作什么 | 画面必须看见什么 | 可用英文字幕 |
|---|---|---|---|
| 1 / 0:00–0:15 | 展示手机、相机与 App 首页 | 两台实体设备同框；相机型号可以用字幕补充 | `ZTransfer running on a physical iPhone with a compatible camera.` |
| 2 / 0:15–0:50 | 按真实连接方式设置相机并连接 | USB：实际插线、相机所需模式；无线：相机模式与手机连接步骤 | USB：`Connect the camera using a compatible USB data cable.` 无线：`Connect the iPhone and camera using the selected Wi-Fi mode.` |
| 3 / 0:50–1:10 | 回到 App，等待连接完成 | 连接状态变化，真实相机照片列表出现 | `The app detects the camera and loads photos from its memory card.` |
| 4 / 1:10–1:40 | 打开一张照片，放大或切换 | App 显示真实相机照片，触摸响应 | `Browse and preview photos stored on the connected camera.` |
| 5 / 1:40–2:20 | 传输一张原片，等待完成，再打开保存位置 | 队列状态、成功结果及保存的文件；下载途中不要切走全部画面 | `Transfer an original photo and verify the saved file.` |
| 6 / 2:20–3:10 | 进入监看，将手或物体移到镜头前；调整一个支持的参数或触发拍照 | 实体动作与实时画面一致；参数或拍摄操作有实际反馈 | `Live view responds to the physical scene. Supported camera controls are operated from the app.` |
| 7 / 3:10–3:30 | 返回，结束连接或拔线 | App 如实回到断连状态，不卡死 | `Disconnecting the camera updates the app's connection state.` |

监看步骤只展示此相机和连接方式实际支持的功能。如代表机不支持某功能，换用已测试的代表机或在审核说明解释限制，不能用模拟画面补拍。

USB、AP、STA 不要求把相同照片浏览和下载重复三遍。主视频先证明一条完整流程；另一种连接方式若是核心卖点或配置明显不同，可补一段 30–60 秒的实际建立连接过程，并在时间索引说明。

## 按审核需要追加的短片段

这些片段不用挤入主视频，也不需要为了录制而购买真实商品。

- **后台 GPS：**若审核需要确认后台定位用途，展示用户主动开启、权限选择、与相机连接、相机收到的定位信息以及关闭功能。地点可选择公开场所；避免展示住宅精确坐标。字幕：`Location sharing starts only after the user enables it. The user can stop it in the app.` 只有实际拍到相机接收结果时才补充“camera receives location”。
- **无相机工作台：**打开工作台，选择一张自有照片，修改一个效果并保存。字幕：`Local photo editing is available without a connected camera.` 最终是否可用以正式版本核对结果为准。
- **内购流程：**开发者会员开通后的 Apple 沙盒或 TestFlight 中另测购买、恢复与取消。不能把本地模拟 Pro 的成功动画当作 Apple 付款成功。审核说明中的内购入口应让审核人员自己操作。

## 拍完后交付

1. 保留原始视频，另导出一份清晰可播放的常见格式，例如 MP4。无需配背景音乐。
2. 把实际时间点替换进下表。若顺序变化，按视频填写，不能照抄预计时间。
3. 提供无需额外申请权限即可打开的视频地址，或使用审核后台实际支持的附件方式。用未登录浏览器检查可访问和播放；链接在审核及补充审核期间保持有效。
4. 给助手视频或可访问地址及上面的设备信息，助手检查字幕、画面可读性、步骤与送审说明的一致性。无需提供 Apple 账户密码或验证码。
5. 送审前在审核说明中加入地址、时间索引和硬件要求。这个视频用于审核，不等于商店宣传预览视频。
