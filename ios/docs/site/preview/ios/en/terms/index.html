Features and compatibility

ZTransfer connects compatible cameras for browsing, photo transfer, live view, supported camera controls and photo effects. Availability depends on model, firmware, connection, permissions and app version.

Use the free features to check your setup before purchasing. Pro removes specified software limits; it cannot enable features the camera does not support. Compatibility information is planned at https://ztransfer.top/ios/support/.

The iOS app does not record live-view video on the phone. Recording control on compatible cameras is a separate feature, with video recorded by the camera.

Free use and Pro

The free version includes 25 successful original-file transfers per day, up to 400 MiB per file, and 180 seconds of actual live-view use per day. Daily limits follow the device's current calendar day, with transfer counts and live-view time recorded separately. Purchasing Pro does not reset free usage already recorded for that day.

Generating effect images, effect filters and frames are also available in the free version. When the watermark feature is used, the free version provides the default watermark, while Pro provides custom watermark options.

While Pro access is valid, these transfer-count, file-size and live-view-time software limits are removed. Device, file-format, storage and connection limitations still apply.
