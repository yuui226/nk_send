# Z传 iOS 全功能快速测试清单

更新：2026-11-05。用途：拿着手机按顺序操作，检查功能、交互和明显性能问题。**这是待执行清单，不是“已经全部测试通过”的报告。**

## 先选一条路线

| 场景 | 怎么跑 | 预计用时 |
|---|---|---|
| 每次改完，快速确认没坏 | 下方“快速路线”的 16 项 | 约 15～20 分钟，首次准备另算 |
| 发布前，完整走一遍 | A～L 共 94 项，完成所有适用项，按章节顺序做 | 核心操作约 90～120 分钟；支付生命周期、长测和多机型另算，可分次完成 |
| 只改了某一块 | 对应整章＋快速路线 | 按改动范围 |

每次复制一份本文件作为该测试包的记录。通过才勾 `[x]`；失败、未测仍留 `[ ]`，在行末写“失败：现象”或“未测：原因”；相机确实不支持的项目写“不适用：型号／原因”。**整行含多个步骤，全部通过才能勾选。**

快速路线共用正文编号，不用重复记结果：

1. 启动与连接：**A01 → A02 → B01**。
2. 浏览与预览：**C01 → C02 → D01 → D03 → D04**。
3. 传输与胶囊：**E01 → E03**。
4. 效果与拨轮：**F01 → F02 → G02**。
5. 监看与重连：**H01 → H03 → B04**。

快速路线需要有可用免费额度或高级版权益；它不能替代无线、GPS、真实购买和异常分支验收。

完整效果和长时间监看需要高级版权益。免费限制最后集中测，避免前面把额度用完。删除输出、覆盖相机预设、重装仅使用测试数据；相机预设选空闲 C 槽，有原配置先自行备份。

## A｜启动、设置、公共控件

- [ ] **A01｜普通启动。**相机先不接，结束 App 后重新打开，立即点设置、切换连接方式。→ 页面可操作，动画不停住；未连接时不假装进入已连接状态。
- [ ] **A02｜设置窗。**打开／关闭 5 次，点右上角 X，也试点空白处和拖动内容。→ 标题和内容是一整块，无白色标题补丁、闪边、突然跳高；X 不会偶发失灵，拖动不误点。
- [ ] **A03｜保存设置。**改每行数量、照片点击／长按操作、照片加载范围，再关开设置并重启。→ 值保留，列表实际行为同步改变；测完恢复自己常用值。
- [ ] **A04｜外观与文字。**切浅色／深色／自动、简中／繁中／英文，并切换现有按钮主题。→ 字不遮挡、不出屏；未自定义的新安装默认液态玻璃。底部参数拨轮保持紧凑，左上角标不压住值。
- [ ] **A05｜公共拨轮。**在设置、筛选、照片效果、工作台各找一个带上下箭头的拨轮，上下连续拖、反向拖、拖到两端后松手，再轻点。→ 可快速调节，松手落到一档，不额外跳一档；边界不无限震动。超过 3 个选项才需要拖动，短选项用轻点；禁用项不改值。
- [ ] **A06｜触感与常亮。**开／关触感反馈后操作拨轮和按钮；开／关屏幕常亮后静置到系统自动锁屏时间。→ 触感服从开关；常亮开启时保持屏幕，关闭后恢复系统行为。不要把系统弹窗自身触感算作 App 开关失效。
- [ ] **A07｜灯泡与帮助。**打开几个页面的灯泡，阅读后关闭，再返回。→ 帮助可读可关闭，按钮颜色清晰稳定；无呼吸效果是既定设计，未读红点按阅读状态变化。
- [ ] **A08｜版本与外链。**看铭牌，打开隐私政策、条款，回到 App；点反馈。→ Debug 带 `-D`，发布包无 `-D`；外链交给浏览器，返回不丢状态；反馈复制联系方式，不应自动发消息。购买窗没有“测试权益／测试 Pro”等多余操作。

## B｜USB 连接（先用最常用相机跑）

- [ ] **B01｜正常接入。**相机开机、MTP/PTP 模式，接正常数据线，记录接线至首屏可用照片的耗时。→ 成功后进入照片列表，优先看到新照片；不能固定空转约一分钟。连接成功图标飞起和页面转场连续，无突跳。
- [ ] **B02｜第一次权限。**仅在还未授权的测试安装上接相机，等待系统权限提示并允许。→ 提示出现前 App 不长时间冻住，允许后可继续连接；已授权设备注明“本轮未覆盖首次授权”。
- [ ] **B03｜未就绪／无卡。**相机关机时接线，再开机；支持且方便时用无卡状态再试。→ 不假装已连好后只显示含糊错误；有可理解的未就绪／连接提示，恢复后能继续。不要求系统无法区分时武断显示“电源关闭”。
- [ ] **B04｜拔插重连。**列表加载完成后拔相机端线，等状态变化再插回。→ 明确断连并可重连，列表可继续用，无旧会话覆盖新状态，无固定一分钟等待；USB 模式只等待对应有线恢复。
- [ ] **B05｜取消与重复进入。**在连接进行中返回／切走，再正常接入；快速关开连接入口。→ 旧任务不会迟到后抢页面、弹成功或建立重复会话，正常接入仍成功。
- [ ] **B06｜信号按钮。**USB 连接后的列表中点顶部信号按钮，再滚动、切队列返回。→ USB 下不响应网络切换；按钮始终在自己的位置，不跑到顶部中央。STA 下也应不响应此点击。

## C｜照片列表与筛选

- [ ] **C01｜加载与滚动。**观察最新一组照片，连续上下滚动、快速滑到底再返回，点 3 个不同日期分组展开／收起。→ 新到旧顺序合理，JPG／NEF 缩略图正常；不串图，日期展开不是整片闪现，滚动不明显停顿。
- [ ] **C02｜加载范围与新照片。**设置较短加载范围，观察较早日期；随后用相机新拍一张。→ 历史缩略图服从范围，新拍照片及时出现且加载缩略图，不被历史范围拦住。监看拍摄后的同类情况还要做 H03。
- [ ] **C03｜连拍分组。**开／关连拍成组，展开一组、进入成员预览再返回／折叠。→ 数量、成员、顺序正确，不丢图、不跳到别组。
- [ ] **C04｜组合筛选。**依次试格式、保护、连拍、未传输，最后组合两个条件。→ 只显示符合条件的照片；无结果有正常空状态；不支持的相机能力不假装可用。
- [ ] **C05｜日期与卡槽。**无日期筛选时进入日期页，两个日期均应为手机当地今天；已有范围较新日期在上。把上面调到下面之前，跨月／闰年调一次，再点完成；返回不保存，再次进入检查。→ 两行独立、不跟随跳动，完成后才按先后归一化；返回丢弃草稿、清除只清日期。双卡机分别选卡 1／卡 2，对应正确、不混图；单卡部分记为不适用。
- [ ] **C06｜评级加载与停止。**开启评级，加载中立即停止，再重开；完成后选不同星级与加载范围。→ 停止确实终止本轮并丢弃已加载评级，下次重新加载；不无限转圈、不把部分结果当完整。卡片原有照片不受破坏。
- [ ] **C07｜重置与弹窗。**设置多个条件并开启评级读取，点筛选窗底部“重置筛选”；关开弹窗、重启检查，再开评级读取。STA 下额外检查从 USB/AP 留下的保护筛选。→ 窗口保持打开、条件恢复默认，评级关闭并丢弃已读数据、范围回到 5 日，下次重新读；隐藏的保护条件也清除，照片加载范围不变。日期／范围拨轮正常拖动，弹窗高度稳定，角标不遮挡。
- [ ] **C08｜照片操作模式。**先用“点击传输／长按预览”，再换成相反模式，各试点击、长按、快速滚动。→ 行为与设置一致；长按及时生效，不需按一秒多；滚动不会误传，长按后松手不再补一次点击。

## D｜照片预览、裁切与入队

- [ ] **D01｜打开／关闭。**从屏幕上、中、下方各打开一张横／竖照片，等 FHD 加载后关闭。→ 缩略图到大图位置连续，FHD 不反复跳位置；返回对应照片，不错误跳回连接页。
- [ ] **D02｜翻页与查看。**左右翻几张，缩放、平移、恢复，切旋转及直方图，查看拍摄信息；试 NEF 和视频条目。→ 当前文件、方向、信息对应；不沿用上一张数据，不支持的操作不假成功。视频重点检查信息／入队，实际播放在保存后的文件验证。
- [ ] **D03｜上滑入队。**上滑入队一次；再做一次斜向上滑和一次距离不足的上滑。→ 完成手势只入队一次；已判为向上时不触发左右翻页；未完成可顺滑回原位，无反复跳动。
- [ ] **D04｜预览效果窗。**预览中开照片效果，改一个参数、关闭；重复两次。→ 与设置里的效果窗共用样式和功能，内容不空白，不是底部抽屉；盖住入队／队列入口但不顶住状态栏；关闭仍是当前照片。
- [ ] **D05｜裁切调整。**用 JPG 打开裁切，试自由、原比例、1:1 和另一固定比例，移动／缩放裁切区域，再取消。→ 边界正确，比例切换稳定；取消回原预览，不误入队、不修改相机原图。
- [ ] **D06｜裁切输出。**重新裁切并用确认／入队操作完成，打开实际输出文件。→ 范围与预览一致，方向正确；EXIF／GPS 在原片有信息时按规则保留；不是只改了缩略图。对不支持裁切的文件有合理禁用或提示。
- [ ] **D07｜操作互斥。**打开效果窗或裁切时试从边缘滑动；连续打开／关闭预览、切下一张。→ 不穿透触发下面的入队、翻页或返回；退出后正常手势立即恢复。

## E｜传输队列与实际文件

- [ ] **E01｜基本传输。**关闭照片效果，传 1 张 JPG、1 张 NEF、1 段短视频。→ 每项正确完成；在“文件”App 的目标目录打开／检查原文件，照片不损坏、视频能播放、大小合理；不只看 App 的“完成”。
- [ ] **E02｜选完再传与暂停。**开启“选完再传”，选 3 张后进队列开始；传输中点暂停，当前结束后再继续。→ 选择阶段不提前开传；暂停按“当前项结束后暂停”执行，后续可恢复，无丢项／重复项。
- [ ] **E03｜速度与剩余数量。**连续传几张较大的照片，观察首次和下一批，并等到完成。→ 速度数字不过快跳动，剩余数量有变化动画；胶囊右边固定、向左变宽，传输→完成→队列按钮连续；卡片速度标签不省略。
- [ ] **E04｜队列交互。**列表和队列来回切换，横向滑动卡片撤回一个等待项，再分别打开清空确认并取消、确认。→ 转场顺滑；撤回目标正确；清空弹窗从按钮附近展开，取消反向返回，确认按钮与弹窗一起淡出，重试按钮不漂移。清空不误取消正在传输／生成的任务。
- [ ] **E05｜失败重试。**传测试文件时断开相机，观察错误，再重连后单项重试；有多项失败时试全部重试。→ 失败原因可理解、状态不假完成；重试能保存完整文件，不重复扣同一次失败的免费次数。
- [ ] **E06｜存放目录。**选测试目录，分别试统一存放、按日期、按类型；再更换目录，最后进入目录选择并取消一次。→ 后续文件位置正确；取消不改原目录；不把完成任务误指向新目录。
- [ ] **E07｜去重与同名。**重复传已成功的原图；只删除测试输出后再传；有条件时传另一张同名但不同内容照片。→ 真正存在的原图不无谓重下，已删文件可重新获得；不同内容不被覆盖或错认成同一张。效果图与原图分别判断。
- [ ] **E08｜实时传输。**依次试关闭、JPG、RAW、视频、全部，按相机格式拍测试素材。→ 只自动加入符合类型的新文件，关闭后不自动加入；历史文件不突然全入队；无法拍 RAW／视频的场景记原因。
- [ ] **E09｜效果任务冻结。**效果方案 A 入队后改成 B，再加入另一张；队列仍有任务时关闭效果总开关。→ 已入队项继续使用入队时方案，新项按新设置；总开关关闭后新任务不生成效果。效果失败重试也不偷偷套用当前方案。
- [ ] **E10｜输出失败恢复。**用测试目标模拟目录失效／不可写或取消授权，再恢复选择有效目录后重试。→ 有失败提示和可用恢复路径，不假报完成，不以空文件覆盖原文件；原片已经保存、效果失败时两种状态区分清楚。无法安全制造时记未测。

## F｜照片效果（从照片列表设置进入；D04 复用同一窗）

先有高级版权益再完整检查；免费限制在 K 章测。每个效果至少保存一张实际输出，不能仅凭预览判断。

- [ ] **F01｜初始目录入口。**没有滤镜目录时点“设置NP3文件目录”，没有 LUT 目录时点对应设置目录入口；各取消一次，再选有效目录。→ 能直接打开系统目录选择；取消不损失已有配置；没有内置的 50 个滤镜自动冒出来。
- [ ] **F02｜拨轮与震动。**导入足够选项后，拖滤镜名称、强度、LUT 参数及颗粒参数拨轮；再试空目录、禁用强度、拖到边界。→ 带箭头的可调拨轮能上下快速调节；只有真正跨档才有档位震动，单纯按住、空列表、边界继续拖不预震。有效的点按入口／成功长按确认可以有自己的反馈。
- [ ] **F03｜分类与长按。**长按滤镜／LUT 名称打开列表，切不同目录分类、同名文件，关闭后再打开。→ 分类、选中项和真实来源一致；长文件名不遮挡，列表能滚动，不需长按一秒多。
- [ ] **F04｜滤镜与 LUT 切换。**选滤镜 A，调整强度；换 B 再回 A；LUT 也这样试，最后在滤镜、LUT、关闭之间切换。→ 强度／微调按对应文件记忆，两个调色模块按互斥规则切换；关闭后不残留上个颜色，不串文件参数。
- [ ] **F05｜微调与收藏。**展开滤镜／LUT 设置，改对比度、饱和度、高光、阴影，试重置；收藏／取消收藏并重开列表。→ 参数、预览、重置结果一致；收藏可再次找到，不产生重复或错指文件。
- [ ] **F06｜目录异常。**选空目录、含无效文件的目录；取消换目录；再恢复正常目录。→ 空／读取失败／无效格式提示合理，不能卡住或留下错图；取消不覆盖原有效选择，恢复后可选可用。
- [ ] **F07｜胶片颗粒。**切各颗粒类型，调强度，换类型再返回，保存横图与竖图各一张。→ 参数记忆正常、颗粒可见且符合强弱变化；静止预览不随机闪动，输出不出现明显拼接线或整图色偏。
- [ ] **F08｜边框。**依次预览现有边框，挑普通边框和参数海报各输出横／竖图；展开边框参数调几档。→ 比例、边距、圆角与文字不截断；参数海报 FL、F 等参数按设计成组带框，不全挤成一行裸文字；参数拨轮紧凑。
- [ ] **F09｜水印。**试文字、自己的透明 PNG，调页面提供的位置和尺寸等参数，边框开／关各看一次，取消图片选择再试。→ 文本和透明背景正确，位置不出界；取消不清掉原水印；不出现已移除的内置品牌图形。
- [ ] **F10｜照片信息。**用有／无 EXIF、横／竖、带 GPS 的测试照片生成边框或参数海报。→ 日期、焦距、光圈、快门、ISO、品牌型号等对应原片；缺字段不继承上一张。原片 GPS 优先，不误替换为当前手机坐标；地名失败不阻塞整项生成。
- [ ] **F11｜模块显隐。**右上角模块显隐菜单逐个隐藏／恢复，试全隐藏，再重新打开。→ 菜单样式与交互一致，开关即时生效；隐藏的模块不偷偷继续作用，恢复和重进后的状态正确，不出空白大窗。
- [ ] **F12｜总开关与方案。**开关总效果，组合滤镜或 LUT＋颗粒＋边框＋水印并保存；试收藏的边框方案后重开。→ 总开关、预览、摘要、实际成图一致，方案参数可恢复；原片不被覆盖，效果开关不会破坏导入目录或收藏。

## G｜本地工作台（连接页底部“照片效果”入口）

- [ ] **G01｜空白与选图。**不连相机进入工作台，从空白区和“选择图片”各打开选择器，取消一次，再多选几张。→ 入口正常，不依赖相机；取消不丢当前图片，多张可切换，顺序和数量正确。
- [ ] **G02｜第二入口与手势。**在工作台做 F01、F02 的目录／拨轮操作，调明显效果，查看预览并保存一张。→ 功能与另一入口一致，拖拨轮不会触发回连接页；按住对比原图后松手能回效果图。
- [ ] **G03｜批量生成。**选横图、竖图与不同尺寸图，设置同一效果后批量保存；生成中取消，再选少量重试。→ 进度对应实际图片，取消后停止后续任务，能再次保存；到系统照片中检查输出，不丢图、不串图、不覆盖原图。
- [ ] **G04｜配置独立。**相机传输效果设为 A，工作台设为 B，监看 LUT 设为 C，来回进入并重启。→ 三者的启用和参数互不覆盖；共享的导入目录／收藏按原设计可复用，但不是把全部配置合并。
- [ ] **G05｜素材与权限异常。**取消图片水印导入，选无效素材或无访问权限的来源；取消／拒绝照片保存权限后恢复。→ 不崩溃、不永久忙碌；原配置可继续用，恢复权限后可重新保存。

## H｜监看、遥控拍摄、监看 LUT

使用相机实际支持的功能；高级版先跑，免费时长最后测。**不测试手机端录制：iOS 暂不提供，这是已确认差异。相机自身的视频录制仍需测。**

- [ ] **H01｜首次进入与帧率。**从照片列表第一次进入监看，缓慢平移相机，再退出重进。→ 转场开头不明显冻住；实际画面连续，不能数字显示几十帧而画面一顿一顿；退出回原列表位置。
- [ ] **H02｜清晰度与组合工具。**分别开 HD、LUT、直方图、波形，再组合打开后平移相机。→ 画面、工具读数继续更新，无明显周期卡顿；关闭后负载应回落。记录相机模式和设置，不只记录 FPS 数字。
- [ ] **H03｜拍摄与新图。**照片模式对焦、按快门，打开回看再退出，回照片列表。→ 相机只拍预期张数，回看是新照片；遮罩整体消失，前摄和底部无分段白条；新照片及缩略图正常出现，不受历史加载范围阻挡。
- [ ] **H04｜曝光与对焦控制。**调页面提供的快门、光圈、ISO、EV、AUTO、白平衡、对焦模式／区域、测光；点画面指定对焦位置，再在相机端改一项。→ 手机和相机状态一致，不可写档位有合理限制；对焦框位置准确、样式稳定，不因失败显示假成功。
- [ ] **H05｜显示工具。**依次试 DISP、网格、水平仪、曝光辅助、直方图、波形、对焦框；电影模式再试音频工具。→ 每个模式可切换和关闭，数据显示对应当前画面；没有上一工具的残留遮挡。
- [ ] **H06｜反挤压与旋转。**切反挤压比例，多次点旋转，再开／关锁定。→ 布局变化无多余黑边／闪白；描边与圆角连续；返回固定合理角落、回看不压 DISP；旋转／锁定两个固定按钮与普通工具略有区别；解除锁定后可正常操作。
- [ ] **H07｜工具编辑。**调整可移动工具顺序，隐藏已开启的工具，再恢复并重进；照片和视频模式各做一次。→ 固定的旋转／锁定不被挤走；隐藏工具停止作用；两模式布局独立、顺序与显隐可记忆。
- [ ] **H08｜监看 LUT 目录。**打开监看 LUT，选目录／取消，切分类与几个 `.cube`，再点关闭。→ 弹窗锚在对应按钮旁，分类与文件分栏，能滚动；应用／关闭即时反映画面，不出现空白窗；这里只改变监看显示，不把 LUT 烧进相机原片。
- [ ] **H09｜监看 LUT 异常。**快速连续选 A→B→C，选无效文件，关闭菜单后退出／重进监看。→ 最终选择与画面一致，旧异步结果不覆盖新选择；失败可恢复，不卡死；不篡改 F、G 的照片调色配置。
- [ ] **H10｜相机预设选择。**打开相机 Picture Control，切已有可选预设；如有 U 档，切物理模式后再试。→ 相机实际值同步；受模式限制时明确提示，不冒充设置成功；无内置 NP3 自动写入。
- [ ] **H11｜用户 NP3 写入。**仅在支持且有空闲 C 槽时，选自己的目录，将已知兼容文件写入空槽并启用；试清除确认的取消和确认。→ 目标槽正确，取消不修改；写入／清除失败可恢复，不碰其他槽；不支持的灵活颜色文件有对应提示。
- [ ] **H12｜延时拍照。**试关闭、2、3、5、10、30 秒；旧版保存 20 秒的配置升级后应为关闭。倒计时中再点快门取消，并分别试退出监看、进回看、后台、断连、切视频模式。→ 只存在一个倒计时，取消后不迟到拍摄；正常倒计时结束才按模式对焦／拍摄；隐藏延时工具后归零，视频模式不误出现照片倒计时。
- [ ] **H13｜相机视频与电脑控制。**支持时切电影模式，开始／停止相机录制并回看文件；另试电脑控制开关和模式限制。→ 录像在相机上实际开始和结束、文件可用；限制状态可理解。不能把相机录制误认成 iOS 手机端录制。
- [ ] **H14｜监看中断。**监看中断线／关闭相机，再恢复；另试锁屏／回前台后重新进入。→ 停止无效取帧，错误可理解、能退出重连，无黑屏永久卡住；不重复触发先前快门或倒计时。

## I｜无线 AP 与 STA（切线集中做）

每种支持的无线方式至少做一次“连接→翻图→传 JPG→监看→断开→重连”。USB 正常不能替代无线通过。

- [ ] **I01｜AP 正常连接。**手机加入相机 Wi-Fi，使用 AP 连接，完成上述小闭环。→ 可用且状态一致；无互联网不妨碍相机本地通信；信号按钮行为符合 AP 页面说明。
- [ ] **I02｜AP 错误与恢复。**先连错 Wi-Fi／关闭相机 Wi-Fi，再恢复正确网络重试。→ 有明确失败与重试，不永久搜索；不会偷偷改走 STA／USB，旧连接不抢新页面。
- [ ] **I03｜STA 首次配对。**手机和相机在同一局域网，按提示在相机确认首次连接。→ 搜索／配对／连接状态快速上下切换，不闪现；真正能读相册和监看后才算成功，不在握手刚确认就假完成。
- [ ] **I04｜STA 已配对重连。**断开再连接同一相机；有条件时切另一台相机再回来。→ 已可信设备正常复用，不无故反复配对；不会认错相机或使用上一台的目录。
- [ ] **I05｜STA 超时与取消。**相机不确认配对、局域网不可达时各试一次，再取消并重试正常连接。→ 等待有界、有可理解的失败；取消后不突然连接成功、不无限重试；恢复后可用。
- [ ] **I06｜STA 重置窗。**打开重置，先取消，再在准备好重新配对时确认。→ 出入有动画，遮罩如有则完整覆盖安全区域，无上下白条；取消不清配对，确认后按重新配对流程成功；按钮不漂移。

## J｜GPS（相机支持时，在有定位条件的地方测）

- [ ] **J01｜首次开启。**连接页 GPS 入口开启，按提示允许蓝牙／定位，在相机完成需要的配对。→ 按钮不是不可用的灰块，定位／找相机／配对状态清楚；室内暂无定位不会假显示已同步。
- [ ] **J02｜同步与实片。**定位可用后点立即同步，切更新间隔，拍一张新照片检查 GPS。→ 手机状态与相机／照片实际坐标对应，不能只看“成功”文案；不误覆盖已有照片原始 GPS。
- [ ] **J03｜停止与重连。**长按关闭 GPS，退出再进入；相机离开后再回来。→ 关闭后不继续同步，重连按已有配对走；App 不因 GPS 状态卡住其他页面。
- [ ] **J04｜权限与网络限制。**拒绝蓝牙／定位后再从设置恢复；试 AP 模式下的 GPS 入口；清配对先取消再按需确认。→ 有可理解引导；AP 不支持时明确限制，不能空转；取消不删记录，确认后可重新配对。
- [ ] **J05｜后台。**在已经获得相应后台定位权限、GPS 开启时锁屏一会再回来，再关闭 GPS 重复。→ 前一种按当前授权继续工作，后一种停止定位工作；无权限不能假称后台同步正常。未授权／未实拍验证则记录未测。

## K｜免费限制与 Apple 购买（最后测，确保手机能上网）

**本节购买操作只用已确认的 Apple 沙盒或本地 StoreKit 测试环境。**TestFlight 使用 Apple 沙盒；Debug 的普通“购买”也走 StoreKit，不等于任意 Debug 包都会假发权益。正式 App Store 购买会真实扣款，不把它当免费的测试按钮。

- [ ] **K01｜商品与界面。**联网打开高级版，切年费／永久。→ 价格、周期、购买和适用时的订阅管理齐全；购买按钮仅“方案名称 · 价格”，末尾无重复“／年／· 永久”；两档反复切换时面板高度不跳变，年度说明始终可见；恢复与适用的管理订阅在底部同行（恢复在左），已有效激活时不显示恢复，无右上角菜单；法律链接保留在设置。面板紧凑，无多余测试按钮／滚动条。中国大陆目标价年费 ¥39.90、永久 ¥99.90；其他商店地区按 Apple 返回的本地价格核对。
- [ ] **K02｜取消／失败购买。**唤起 Apple 购买后取消，再试无互联网加载商品。→ 取消不授予权益、不当作成功庆祝；失败可理解、恢复网络后可重试，无一直锁死的按钮。
- [ ] **K03｜两类成功购买。**使用分别准备的沙盒购买历史测年费、永久，购买后关开高级版并重启。→ 验证后显示正确权益，相关限制解除；不会每次启动闪回免费。不用已经买了永久的同一状态证明年费首次购买正常。
- [ ] **K03a｜年费续费窗。**设置顶部点“续费”。→ 标题“续费”，只显示当前续费／到期日期及适用状态；管理订阅在日期旁。有效期内无两档选择、购买／升级永久或恢复按钮；取消续订仍保留本期权益，改显示本期到期日。到期恢复免费后，重新提供年费与永久两档。
- [ ] **K04｜恢复与离线。**同一 Apple 测试账户重启后先检查权益自动恢复，不点任何恢复按钮；仅在没有有效权益时检查购买窗底部“恢复购买”的手动补救路径；已购状态不应显示恢复。重启后接无互联网的相机 AP，再看权益和操作。→ 恢复正确、不重复购买；网络暂时不可用不随意抹掉已确认的有效权益。清装恢复用备用设备或已备份测试数据另测。
- [ ] **K05｜年费生命周期。**通过沙盒账户工具分别安排续订、关闭续订、到期／退款，再让 App 同步。→ 关闭续订不立即失去未到期权益，有效期内仍不提供升级永久；到期／撤销恢复免费后能重新选择两档。若账户历史已有永久与年度共存，保留真实永久权益和原年度管理入口，不声称自动取消年费。没有准备这些状态就记未测。
- [ ] **K06｜免费额度。**在无有效付费权益的测试状态，检查每日 25 次原片成功传输、单文件上限 400 MiB、每日实际监看 180 秒；用失败重试、重复回调／重复点击、退出监看验证边界。→ 失败不当成功扣次，限额不被重启绕过；监看准备／等待无画面不白扣时长；付费功能正确拦截，不半途假完成。自然日刷新可次日补测，不要靠改系统时间制造通过。
- [ ] **K07｜测试权益隔离。**若测试包确实启用了 Debug 模拟 Pro，连续点铭牌 7 次（相邻间隔小于 1.5 秒）后看状态；发布包核对无此模拟入口。→ 只清除 Debug 模拟权益，不删除真实 StoreKit 购买、不重置当日用量。已有真实购买时不会强制变免费；无模拟权益则此分支不适用。

## L｜权限、持久化、兼容与性能收尾

- [ ] **L01｜权限拒绝后恢复。**用适合做权限测试的安装，逐个拒绝／恢复实际请求的相机控制、局域网、照片保存、蓝牙、定位；目录选择也取消一次。→ 当前功能给出对应引导，不影响无关功能、不反复强弹；在系统设置恢复后能重试。已授权且无法复现首次提示的分支如实记未测。
- [ ] **L02｜重启与覆盖更新。**先记录目录、语言、主题、滤镜／LUT、收藏、工具布局和权益，结束 App 重开；拿到下一测试包后覆盖安装再看。→ 应持久化配置保留，失效目录可恢复。队列任务是会话内状态，不把“杀进程后队列仍完整恢复”当已有承诺；已经保存的文件必须还在。
- [ ] **L03｜屏幕与弹窗。**当前手机试大字体、浅／深色；有另一尺寸手机或 iPad 时跑 A02、D04、G02、H06、K01。→ 主按钮可见可点，长文可读，遮罩完整，前摄／底部区域无白条。iPad 首发是竖屏兼容策略，不把未承诺的自由横屏／分屏列为缺陷。
- [ ] **L04｜快速交错操作。**滚列表时开关筛选、预览时退出、传输时切队列、监看时开关工具，重复几轮，再后台／前台一次。→ 不崩溃、不串页面、不重复动作，退出的弹窗不拦后续点击；上滑、左右翻页和拨轮拖动不互相误触。
- [ ] **L05｜静置发热。**亮度保持相同，分别在无相机连接页、断连后的照片列表静置约 5 分钟，记录是否充电、开始／结束温感与电量。→ 没有持续明显升温／掉帧；断线后不反复读图／取帧或扫描无关连接方式。摸起来热先记条件与时间，单靠手感不能证明 CPU 已达标，需要时再采样。
- [ ] **L06｜持续负载与释放。**高级版下监看约 10 分钟，平移并组合开 HD／LUT／波形；另跑一批传输与效果生成，再停止、退出、断连静置。→ 无持续恶化的卡顿／崩溃；停止任务后负载应回落，不残留录制、定位、渲染或无限重试。比较时保持亮度／充电／环境接近，视频记录实际卡顿。
