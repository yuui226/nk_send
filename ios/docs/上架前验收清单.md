## 相机审核视频拍摄脚本

1. 拍到 iPhone/iPad、相机和连接线或相机 Wi-Fi 设置，能识别真实硬件。
2. 从 App 连接页开始，展示相机端必要设置和连接成功。
3. 展示照片列表，选择一张照片并完成传输，展示实际结果。
4. 展示监看画面并移动相机，让拍摄内容变化；展示支持的相机控制操作。
5. 如支持且属于审核重点，展示 GPS 开关和用途；不要展示真实家庭坐标。
6. 展示高级版购买及恢复入口。使用真实提交版本的界面，不用 Debug 假支付证明购买成功。
7. 助手整理简洁英文字幕与时间点。视频链接必须让审核人员无需额外申请权限即可访问。

这是拍摄真实设备的审核视频，普通屏幕录制可以辅助说明，但不能代替 Apple 所要求的硬件交互拍摄。[Apple 要求](https://developer.apple.com/help/app-review/before-submitting-for-review/complete-review)
