| 已配对重连 | 优先系统已连接/已知UUID，再服务过滤扫描；没有完整身份不直连。4.5秒直连回退、15秒扫描/已配对setup、7秒握手、1.5秒ID兜底、3秒重连ID确认、30秒系统配对期限均核对。重新认证后立即发送新会话第一笔GEO，不沿用旧发送间隔。 |
| GPS数据 | 41字节GEO、UTC时间、经纬度方向/分段、海拔符号/范围与安卓向量一致；无可靠海拔时发0，后续可信海拔补写。可信海拔缓存两分钟/一公里边界，取系统缓存也限制两分钟。iOS无卫星数公开接口，保留既有0值适配。 |
| 四档频率、手动同步 | 30/60/120/300秒按成功ACK重新计时，静止时仍周期写入；当前写入串行，手动同步不排入第二笔。运行中改频率保留蓝牙会话，修改定位精度并取消旧倒计时；新增测试验证在途ACK、新倒计时、迟到旧唤醒、重复选择与关闭后的迟到ACK。 |
| 关闭、断开、错误 | 关闭先发布OFF，再停止蓝牙，取消定位、写入期限、重连、状态过渡；旧回调不能复活。普通断连800ms后恢复；普通错误5秒恢复；配对类错误等待显式操作。GEO显式失败不更新发送时间，10秒无回应走失败恢复。蓝牙关闭暂停，开启由适配器事件恢复。 |
