2026-10-20。这份检查验证 `.app` 的打包内容，不代表已通过真机、购买、签名或 Apple 审核。

## 检查命令

在仓库根目录执行，最后一个参数替换为实际生成的 Release `.app` 路径：

```sh
python3 ios/scripts/verify-release-bundle.py "/实际构建目录/ZTransfer.app"
```

脚本只读取文件，以 JSON 输出结果；`packagingChecksPassed: false` 或非零退出值都必须先查原因。不要通过删除报告中的失败项来“通过检查”，应修改工程打包配置并重新生成产物。

目前自动核对：

- Bundle ID 为 `com.ztransfer.ios`，有版本及构建号；
- 最低 iOS 16.0，同时支持 iPhone/iPad；若产品计划变更，先更新计划和对应检查；
- 打包的 `PrivacyInfo.xcprivacy` 与工程源文件一致；
- `Resources/licenses` 下全部 `.txt` 许可/通知和三个水印字体与源码内容一致（包含 AndroidX、AOSP、Skia 既有许可，不仅检查新增汇总文件）；
- 没有两张指定 Debug 样片、本地 StoreKit 配置、XCTest 测试包或 Debug 预览动态库；
- 主可执行文件不包含已移除的 `App-Prefs:` 路径及启动代码中列出的 UI 测试参数。

字符串检查不是完整安全审计，也不能证明所有 Debug 代码都已排除。最终还需结合资源清单、条件编译、依赖与实际运行结果。

- 隐私与条款 URL 已真实部署、能访问，并接入正式 App；脚本只报告当前值，不访问网站。
- Apple 签名、正式设备 Archive、归档验证和上传；模拟器包不能用于 App Store 发布。
- 发布截图、商店文案、内购商品、审核说明与同一版本一致。
- 所有权限、真实硬件、后台运行、内购沙盒以及实际页面检查。
