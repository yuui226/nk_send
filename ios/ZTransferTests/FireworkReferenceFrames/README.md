# 烟花关键帧基准

这 8 张 PNG 来自优化前的生产 Canvas 绘制公式，仅将绘制函数提取出来以固定时间采样。
来源：`/tmp/ztransfer-fireworks-before.log`／`.xcresult`，iOS 26.5 模拟器，ImageRenderer scale=1，
256×384 pt 白背景，seed=1／4，elapsed=200／480／1200／1800 ms。
已查看上升和爆炸帧，确认不是空白渲染。

`PremiumFireworksTests` 将新绘制结果与这些基准统一转换成 RGBA 后逐像素比较。
覆盖上升、起爆、展开和消散，验证本次静态参数预计算不会改变原画面；
不代表 Android 像素截图对比、真实屏幕帧率或全部设备／色彩空间均已验收。

基准属于测试资源，不打包进正式 App。不得为通过测试直接覆盖基准；系统渲染变化或设计调整
需要先核对原因和原始视觉／动画要求，再明确记录是否更新。
