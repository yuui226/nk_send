# 监看工具栏自定义与辅助工具需求清单

> 整理日期：2026-09-21  
> 状态：功能代码已实现，Debug 构建及本地针对性验证通过；相机相关能力、完整录制交互与真机性能仍待联调，见第 11 节。  
> 范围：监看工具偏好持久化、布局锁定、白平衡与对焦区域调整、曝光辅助与波形图、工具栏管理。  
> 快门 PC 控制兼容问题已暂时跳过，不作为本需求的前置条件。

## 1. 已确认的整体行为

- 用户退出监看页、杀死 Z传或重启后，工具开关和档位应保留；纯净全屏状态不持久化。隐藏工具时同时关闭其功能，重新显示入口不自动启用功能。
- 横竖屏共用工具定义、普通工具相对排序和显示配置，仍保留各自布局；全屏与旋转固定在右侧，不参加自由排序。
- 新增锁定布局、白平衡调整、对焦区域调整、伪色、波形图。
- 斑马纹和伪色合为一个“曝光辅助”按钮：**关闭 → 斑马纹 → 伪色 → 关闭**。
- 波形图保持独立，可以与斑马纹或伪色同时使用。
- 新增小尺寸齿轮管理按钮，固定在普通工具序列最后；全屏与旋转属于独立的右侧固定区域，其位置规则优先。
- 点击齿轮弹出管理弹窗，功能仅为拖动排序和显示开关；关闭显示时同时关闭对应工具功能，端侧录制正在运行或暂停时先正常停止录制再隐藏。

## 2. 工具管理入口与弹窗

### 管理入口

采用**齿轮图标**。该入口管理的是工具配置，用齿轮比画笔更容易理解。

- 尺寸、圆形按钮外观、按压反馈与现有小工具一致，遵循当前材质主题。
- 在横竖屏中都固定为普通工具序列最后一项，换行后仍遵循该顺序；不排到全屏、旋转的右边，也不挤占它们的固定区域。
- 管理入口本身不可隐藏、不可拖动，不参与可配置工具列表。
- 不增加工具栏外的大按钮或独立文字入口。

### 管理弹窗

标题建议为“管理工具”。采用简约列表：**复用的工具图标 + 明确名称 + 拖动手柄**。

- 图标必须复用监看工具栏的同一套绘制资源，避免同一个功能出现两种图案。
- 每个条目显示工具名称，使弹窗同时承担图标说明的作用。全屏、旋转仍展示名称和显示开关，但不提供拖动手柄，可用简短“位置固定”说明，避免暗示可以移动。
- 点击图标或名称区域切换显示状态；独立拖动手柄用于排序，避免拖动时误切换。
- **亮起表示在工具栏显示，黯淡表示在工具栏隐藏。**黯淡条目的名字仍需清晰可读，并且仍可点击和拖动。
- 亮起表示入口可见，不代表功能已启动；切换为黯淡时同时关闭工具功能并隐藏入口。重新亮起只恢复入口，不自动启动功能或录制。
- 隐藏工具仍保留在列表中。普通工具保留其排序位置；全屏、旋转重新显示时回到右侧固定区域。
- 调整即时生效并持久化，关闭弹窗不撤销；无需“保存／应用”二次操作。
- 弹窗内容超出高度时内部滚动，适配横屏、窄屏、大字体与安全区域。
- 使用现有主题配色、字体、圆角和表面层次；避免厚重边框、强阴影、花哨渐变或额外装饰。
- 本轮不加入预设方案、分组、恢复默认、功能参数设置等其他管理能力。
- 辅助功能描述需要表达工具名称、显示/隐藏状态及移动操作，不能仅靠颜色传递状态。

### 隐藏与运行状态的关系

用户已确认：**隐藏按钮，同时关闭该工具功能。**不保留“工具入口已隐藏、功能仍在运行”的状态。

- 参考线、曝光辅助、直方图、波形图、水平仪、帧率及音频电平等隐藏时停止显示，并停止仅由该工具启用的计算或轮询。
- 隐藏 HD 时关闭高清监看；隐藏反挤压时恢复正常比例。原倍率、样式等参数可保留为下次启用的偏好，但实际启用状态必须为关闭。
- 隐藏锁定布局时解除方向冻结、恢复正常方向监听；隐藏纯净全屏入口时退出全屏（若正在全屏）。隐藏手动旋转入口不重置当前方向，也不等同于锁定方向。
- **端侧监看录制正在运行或暂停时，隐藏录制按钮应触发正常停止、完成文件收尾，再隐藏。**不再采用“录制时禁止隐藏”的方案；不丢弃已录内容。收尾期间防止重复操作，异常必须可见，不能假装已经停止和保存成功。该行为不扩展为停止相机机身录像。
- 白平衡和对焦区域属于相机参数调整入口，隐藏时关闭对应面板并隐藏按钮，不重置或回滚已经写入相机的参数。
- 隐藏状态与功能关闭状态一同保存，重启后不能恢复为隐藏但开启。重新显示按钮只恢复入口，功能保持关闭；本版再次主动启用时从默认首档开始；额外记忆隐藏前档位留作后续优化。
- 管理弹窗仍只保留一套显示开关，不增加独立的功能启停开关。

## 3. 工具清单与建议名称

以下是整理清单，**不是最终默认顺序**。保留现有普通工具的相对顺序，新工具默认插入位置在实施时结合布局确定；齿轮在普通工具序列最后，全屏、旋转保持右侧固定位置。

| 工具名称 | 工具栏行为 | 状态保存与能力要求 |
|---|---|---|
| 高清监看 | 切换 HD | 保存用户选择；相机不支持或启动失败时按实际能力处理 |
| 帧率显示 | 显示／隐藏 FPS | 保存开关 |
| 音频电平 | 显示／隐藏音频电平 | 保留现有持久化；实际显示沿用录像模式及数据可用条件 |
| 直方图 | 显示／隐藏直方图 | 保存开关 |
| 参考线 | 沿用现有样式循环 | 保存具体样式，保留无实际画面时也能查看样式的行为 |
| 曝光辅助 | 关闭 → 斑马纹 → 伪色 → 关闭 | 保存具体档位；图标反映档位，不弹气泡提示 |
| 反挤压 | 沿用倍率循环 | 保留现有倍率持久化 |
| 水平仪 | 显示／隐藏水平仪 | 保存用户偏好；机型不支持时不显示虚假读数 |
| 监看录制 | 沿用端侧开始、暂停、停止流程；隐藏时正常停止并收尾 | 仅保存入口配置，不恢复正在录制的状态；仍保留现有功能权限 |
| 纯净全屏 | 沿用全屏入口与返回方式；固定在旋转左侧，不参与拖动 | 全屏状态不持久化，入口显隐仍持久化；不得绕过方向冻结 |
| 旋转布局 | 沿用手动切换方向；固定在右侧区域最右，不参与拖动 | 可控制入口显示；锁定时不可改变布局 |
| 锁定布局 | 锁定／解锁当前方向 | 保存锁定状态和锁定方向 |
| 白平衡 | 打开白平衡调整面板 | 每次连接读取相机真实值，不自动写入上次值 |
| 对焦区域 | 打开对焦区域选择面板 | 按相机能力提供区域选项；本轮不新增 AF-S/AF-C/MF 模式切换 |
| 波形图 | 显示／隐藏波形图 | 保存开关；第一版建议做亮度波形 |
| 管理工具 | 打开管理弹窗 | 普通工具序列最后、始终可见，不进入排序列表；不占用全屏/旋转固定区域 |

调试入口继续遵循现有调试解锁规则，不因这次工具管理而对普通用户直接开放。

## 4. 持久化范围

### 必须保存

- 可开关工具的实际启用状态与档位；隐藏后的实际状态必须为关闭。可另存上次使用的参考线样式、反挤压倍率、曝光辅助档位，供用户下次主动启用使用。纯净全屏除外。
- 工具排序和显示／隐藏配置。
- 布局锁定状态、锁定时的方向。
- 新增工具未来具有的用户显示参数，应进入同一偏好管理方式。

### 需要区别的状态

- **用户偏好**与**当前相机是否可用**分开保存。暂时不支持某工具，不应抹掉用户偏好。
- 相机的白平衡、对焦区域、对焦模式、曝光等参数以相机当前值为准，重连读取，不自动恢复写入。
- 纯净全屏不持久化；重新进入监看页使用常规布局，但仍恢复已保存的锁定方向。正在录像、正在对焦、网络请求、调试 PC 控制等运行状态不随 App 重启自动继续。
- 首次升级应保留已有音频电平、反挤压设置；未设置过的工具沿用现有默认行为。
- 使用稳定工具标识和档位标识，避免以后增删工具或调整枚举顺序造成偏好错位。

## 5. 布局锁定

锁定布局的含义仅为**冻结方向**，不是锁定工具排序、显示配置或所有界面操作。当前监看页由内部布局处理竖向、左横向、右横向显示。

开启锁定时：

1. 以当前已经显示的方向为锁定方向。
2. 停止方向监听，不只是忽略回调。
3. 取消待执行的方向稳定延时、队列请求，避免锁定后仍转动一次。
4. 手动旋转按钮保留原位并变暗不可操作（若用户已隐藏则保持隐藏）；全屏入口也不能强制转横屏。工具管理、排序和其他工具操作仍可使用。
5. 重新进入页面时直接恢复锁定方向，避免先竖屏再闪到横屏。

解除锁定时恢复正常的方向检测和防抖机制。横竖屏、全屏、返回页面和 App 前后台切换均需遵循锁定状态。

## 6. 新工具实现范围

### 白平衡

- 新增 WB 图标入口，面板显示当前白平衡和相机实际提供的选项。
- 第一阶段优先模式切换；色温与微调是否加入，取决于目标相机可读写能力。
- 不硬编码一套所有机型都可写的选项；只读或不支持时给出对应状态。
- 写入后读取确认，并适配相机端修改后的刷新。

### 对焦区域

- 用户明确需要的是**调整对焦区域**，不是 AF-S、AF-C、MF 对焦模式切换；本轮仅新增区域调整入口。
- 面板显示相机当前区域，以及相机实际支持的区域选项，例如单点、宽区域、自动区域等；不硬编码所有机型都有同一套列表。
- 分别验证照片和视频模式、AP/STA/USB 的能力；当前对焦模式可能影响区域是否可选，按实际能力显示，不自动更改对焦模式来强行解锁选项。
- 写入后读取确认，并刷新现有点击对焦、跟踪与区域框相关状态；不能只更新文字而让对焦行为沿用旧区域。

### 曝光辅助：斑马纹／伪色

- 一个按钮三档循环，保留现有斑马纹能力并增加伪色。
- 斑马纹与伪色同一时间只显示一种，属于本次交互选择，不是协议或算法上的必然限制。
- 伪色第一版建议固定一套配色，提供可理解的图例；不先增加多套预设。
- 根据相机传来的监看图像分析，不宣称反映 RAW 原始曝光或未经处理的传感器信号。
- 不修改拍摄照片或相机设置；辅助图像坐标需与反挤压后的显示、旋转和有效图像区域一致。

### 波形图

- 保留独立开关，第一版建议亮度波形，可与曝光辅助并用。
- 有效图像区域不包含界面黑边、文字、参考线或伪色层；分析原始监看帧，避免分析到自身绘制的辅助层。
- 复用已经解码的画面，限制采样量和刷新频率；关闭时不计算。
- 与直方图、音频电平等同时显示时要安排位置，不能相互覆盖到无法阅读。

## 7. 横竖屏共用工具定义

统一的是工具的标识、名称、图标、行为、状态、排序和显示配置；各方向仍有各自布局容器。

- 竖屏继续使用适合竖屏的位置和换行方式。
- 横屏继续使用适合横屏的位置和间距。
- 两个容器消费同一份有序工具列表，新增或隐藏工具无需分别维护两套按钮定义。
- 普通工具按用户顺序排列，最后追加齿轮；全屏、旋转由独立固定区域布局。不能将固定按钮混入自由排序后依靠“最后两项”推测身份。
- 因拍摄模式暂时不显示的工具保留配置位置，重新可用时回到原位。

### 全屏与旋转的固定位置（用户补充确认）

- **竖屏：**全屏、旋转只在第一排右侧出现，整体对齐监看画面下方工具栏的右侧安全边界。即使普通工具不足一行，也通过中间留白保持固定位置，不能紧跟普通按钮向左收缩，更不能掉到第二排。
- **横屏：**全屏、旋转保持工具栏第一排最右侧固定区域，不进入普通工具的自由排序及换行序列；右侧以当前横屏工具栏的可用边界为准，保留现有面板和安全间距。
- 两者从左到右沿用 **全屏 → 旋转**。默认保持显示，管理弹窗可以隐藏入口；显示时固定位置的规则始终有效。
- 隐藏其中一个，另一个仍对齐右侧；都隐藏时释放该固定区域。普通工具的排序不会因它们显隐而改变。
- 第一排先为可见的固定按钮预留宽度，普通工具放不下则按顺序移到后续行。齿轮是普通序列末项，允许随普通序列换行，不要求占用第一排右侧。

单行示意（空白代表用于保持右侧位置的剩余空间）：

```text
[HD] [参考线] [齿轮]                 [全屏] [旋转]
[齿轮]                              [全屏] [旋转]
```

实施结果：横竖屏仍共用 `AdaptiveRemoteToolBar`，但固定项数量按显隐动态计算，固定区起点改为“可用宽度减固定区宽度”。已在模拟器验证只剩齿轮时，两种布局的全屏／旋转仍位于第一排右侧。

## 8. 录制输出与实施细节

### 用户已确认的监看录制输出

- 端侧录制保留监看画面本身，以及用户启用的反挤压效果。
- **不录入辅助图层**：参考线、斑马纹、伪色、直方图、波形图、水平仪、FPS、音频电平、对焦框等 App 叠加内容。
- 录制取帧与分析、绘制链路应分开，不能对已经绘制辅助层的界面直接录屏；实际录制行为必须通过输出视频验证。
- 这里排除的是 App 叠加的辅助内容；相机本身已嵌入源画面的内容无法仅靠跳过 App 图层移除。

### 尚需实施时确定的细节

- **新增工具默认排序与可见性：**在当前布局中确定，管理齿轮处于普通工具序列最后、全屏/旋转固定右侧的规则不变。
- **伪色图例和波形图位置：**按现有监看布局安排，避免与其他辅助工具相互遮挡。
- **相机控制能力：**WB 和对焦区域可选项必须经协议查询、写入回读和必要真机验证，不能以按钮做好作为功能完成标准。

## 9. 建议实施顺序与验收

### 实施顺序

1. 统一工具定义与偏好管理，实现管理弹窗、排序、显示开关和状态持久化。
2. 加入布局锁定，处理手动旋转、全屏、方向事件与恢复顺序。
3. 加入白平衡、对焦区域设置，并验证相机读写能力。
4. 将斑马纹升级为曝光辅助三档，加入伪色及亮度波形，完成性能和显示适配。

### 首版边界与后续联调重点

1. **白平衡先支持模式选择。**色温数值和微调未扩展。对焦区域只给已确认的标准编码命名，未验证的厂商编码显示“相机选项 + 编号”，不能据此宣称所有 Z 机型区域名称已适配。
2. **不为解锁参数自动改变相机控制模式。**只读属性保持不可写，不自动进入完整 PC 控制，不切换 AF-S／AF-C／MF。需要分别在照片／视频及 AP／STA／USB 下核对相机实际能力。
3. **图像分析基于收到的 JPEG 亮度。**上限 256×192 采样、125 ms 刷新间隔；关闭时不计算，两个工具共用采样。伪色显示更新因此最高约 8 次／秒，真机联调需重点评估动态监看观感；不代表 RAW 或经过标定的传感器曝光。
4. **录制中切换反挤压不会改变 MP4 分辨率。**新比例居中适配开录时的输出画布，可能出现留黑；这是保持同一文件连续编码的处理方式。原始比例录制保留直接取像素路径。
5. **隐藏后重显保持关闭。**本版没有另存隐藏前的参考线／曝光辅助档位，用户再次点击从首档开始；正常退出、重进而未隐藏时，具体档位完整恢复。
6. **故障不伪装成功。**MP4 必须实际执行 muxer 收尾成功才显示保存成功；部分文件仍保留供恢复。相机写入必须回读确认；设备变化或只读时不提交旧值。

协议取值参考 libgphoto2 的 `camlibs/ptp2/ptp.h` 与 `config.c`：
[源码](https://github.com/gphoto/libgphoto2/tree/master/camlibs/ptp2)。公开源码中的属性定义是实现依据，不能替代目标机型的真机验证。
